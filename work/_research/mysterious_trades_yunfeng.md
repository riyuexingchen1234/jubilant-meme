# 十大神秘/灰色职业调研报告

**调研日期：** 2026年6月30日
**信息来源：** 新闻报道、行业文章、从业者自述、论坛帖子、历史资料
**职业筛选标准：** 公众听说过但了解不多、带有神秘色彩、处于法律或道德灰色地带、具有"盗墓质感"的行业

## 一、摸金校尉（盗墓者）

### 1.1 职业概述

**真实存在，但绝大多数是违法犯罪行为。**

"摸金校尉"一词起源于三国时期，相传曹操为弥补军饷不足，设立发丘中郎将、摸金校尉等军衔，专司盗墓取财。这一说法最早见于陈琳《为袁绍檄豫州》，但史学界对此有争议，认为可能是檄文抹黑。

现代意义上的盗墓者，民间俗称"盗墓贼""挖坟的""土夫子"（南方），是一个古老而神秘的地下职业。他们以非法挖掘古代墓葬、盗取文物为生，与考古队的"抢救性发掘"有着本质区别。

### 1.2 真实工作内容与日常

**作案流程（根据警方披露案例整理）：**

1. **踩点寻墓：**
   - 查阅地方志、族谱、古籍，寻找古墓线索
   - "望气"：观察地形地貌，利用风水知识定位（真实存在，很多盗墓贼懂风水）
   - 使用洛阳铲探土，根据土色、土层结构判断墓葬位置和年代
   - 夜间用强光手电照射山坡，观察植被差异（古墓上方植被往往不同）

2. **盗掘：**
   - 团伙作案，分工明确：有人负责探墓、有人负责挖掘、有人负责放风、有人负责销赃
   - 作案时间多选在深夜或凌晨，避开人群
   - 盗洞讲究精准，直接打到墓室，少走弯路
   - 大墓可能需要几天甚至几周时间挖掘

3. **取货与销赃：**
   - 进入墓室后，优先拿取价值高、体积小的物件（玉器、金银器、瓷器等）
   - 通过地下文物黑市销赃，或通过"中间人"流向海外
   - 出土文物被称为"生坑货""鬼货"

**真实日常（非小说）：**
- 不是天天盗墓，大部分时间在踩点、寻墓、等机会
- 常年混迹于古玩市场、文物商店，打探消息、寻找买家
- 收入极不稳定，"三年不开张，开张吃三年"但风险极高
- 普通盗墓者其实赚不到大钱，大头都被上层"老板"和境外买家赚走了

### 1.3 行业规矩与黑话

**行规（传说居多，真实性存疑）：**
- "鸡鸣灯灭不摸金"：小说中的规矩，现实中是否存在不确定
- 盗墓前要拜神、烧纸（部分地区确实有此习俗）
- 不拿墓主随身贴身之物（迷信说法）
- 团伙内部分赃有固定比例

**黑话：**
| 黑话 | 含义 |
|------|------|
| 倒斗/挖窑 | 盗墓 |
| 土夫子 | 盗墓者（南方） |
| 摸金/淘沙 | 盗墓 |
| 坑口 | 墓穴 |
| 生坑 | 新出土的（文物） |
| 熟坑 | 出土后经盘玩的 |
| 鬼货 | 盗墓出土的文物 |
| 铲地皮 | 下乡收货（有时也指盗墓） |
| 吃仙丹 | 买到便宜好货 |
| 吃药 | 买到假货/出事了 |

### 1.4 真实风险

1. **法律风险（最大）：**
   - 盗掘古文化遗址、古墓葬罪，可处三年以上十年以下有期徒刑
   - 情节特别严重的，可处十年以上有期徒刑或者无期徒刑
   - 盗窃珍贵文物，造成文物损毁的，处罚更重
   - 2025年公安部"打击文物犯罪专项行动"，打掉团伙300余个，抓获嫌疑人2000余名

2. **人身安全风险：**
   - 古墓可能有机关（但现实中很少，大多是传说）
   - 盗洞坍塌是最常见的事故，每年都有盗墓者被埋致死的案例
   - 墓室缺氧、有毒气体（水银、沼气等）
   - 团伙内斗、黑吃黑（为了分赃不均杀人灭口真实存在）

3. **健康风险：**
   - 古墓中细菌、病毒、霉菌，可能引发疾病
   - 长期在阴暗潮湿环境中工作，易患风湿、关节炎等

4. **销赃风险：**
   - 文物黑市鱼龙混杂，可能被"黑吃黑"
   - 警方盯紧文物市场，销赃渠道越来越窄
   - 出土文物一旦被发现，随时可能被追缴

### 1.5 与小说/想象的差距

| 小说/影视 | 现实情况 |
|----------|---------|
| 摸金校尉神通广大，上知天文下知地理 | 多数盗墓者文化程度不高，靠经验和师傅带，专业知识有限 |
| 古墓机关重重，惊险刺激 | 绝大多数古墓没有机关，最大的危险是坍塌和缺氧 |
| 随随便便就能找到大墓 | 找墓很难，很多时候挖下去是空的或已被盗过 |
| 一夜暴富，富可敌国 | 普通盗墓者赚的是辛苦钱，真正赚大钱的是幕后老板和境外买家 |
| 个个身手不凡，飞檐走壁 | 就是普通农民、无业人员，很多是临时组队 |

## 二、捞尸人（长江水鬼）

### 2.1 职业概述

**真实存在。** 这是一个与死亡打交道的古老职业，主要在江河湖泊边从事打捞尸体的工作。

不同地区有不同的称呼：
- 长江流域："捞尸人""水鬼""打捞队"
- 黄河流域："黄河捞尸人""河工"
- 官方称谓："水上打捞员""溺水救助队员"

这个职业之所以神秘，一是因为与死亡相关，人们避讳谈论；二是因为行业内有很多讲究和禁忌，外人难以了解。

### 2.2 真实工作内容与日常

**主要工作：**

1. **打捞尸体：**
   - 接到报警或家属求助后，出船打捞溺水者遗体
   - 打捞方式：用带钩的竹竿、渔网摸索，或潜水打捞
   - 有时需要在水中搜寻数小时甚至数天
   - 尸体打捞上岸后，协助家属处理后事

2. **其他打捞业务：**
   - 打捞落水车辆、货物、船只
   - 水下工程辅助作业
   - 协助警方水下取证

**真实日常（根据长江捞尸人自述整理）：**
- 工作时间不固定，24小时待命，接到电话就得出动
- 常年在船上生活，风吹日晒
- 收入来源：家属支付的打捞费、政府补贴、其他打捞业务
- 长江打捞费一般几千到几万不等，看难度和家属经济情况
- 有时遇到困难家庭，会少收或不收钱

**从业者画像：**
- 多为中年男性，渔民出身，水性好
- 很多是子承父业，世代相传
- 文化程度普遍不高，但经验丰富
- 性格大多沉默寡言，不喜欢多谈工作

### 2.3 行业规矩与禁忌

**行业讲究（真实性待核实，多为传说与习俗混合）：**

1. **"捞尸不捞活人"？**
   - 假的。遇到活人肯定要救，这是底线。
   - 但确实有"只捞尸体、不救活人"的说法，因为救人是见义勇为，捞尸是职业——这更多是外界的误解。

2. **"不见尸体不报价"：**
   - 真实。因为打捞难度差异大，没看到尸体前没法定价。
   - 也有"先报价再捞"的，容易引发"挟尸要价"的争议。

3. **捞上来的尸体不能让脚沾地：**
   - 部分地区有此习俗，要用布或担架抬。
   - 说是怕"魂留在地上"，其实更多是对死者的尊重。

4. **不捞直立的尸体（"站尸"）：**
   - 传说中水中直立的尸体"怨气重"，不能捞。
   - 现实中确实有尸体因腐烂胀气等原因直立在水中的现象，但捞尸人不会因为迷信而不捞，只是会更谨慎。

5. **捞尸前要烧香、烧纸：**
   - 很多捞尸人确实有这个习惯，既是求平安，也是对死者的尊重。

**黑话/行话：**
| 行话 | 含义 |
|------|------|
| 上水 | 尸体从上游漂下来 |
| 下水 | 往下游寻找 |
| 漂子/货 | 尸体（避讳说法） |
| 顺河走 | 顺着水流方向找 |
| 靠岸 | 打捞上岸 |

### 2.4 真实风险

1. **人身安全风险：**
   - 水上作业本身就有危险，翻船、溺水都可能发生
   - 恶劣天气（大风、暴雨）下作业风险更高
   - 打捞过程中可能被水中杂物、鱼钩等划伤
   - 2024年长江某打捞队就有队员在打捞时被急流冲走牺牲

2. **健康风险：**
高度腐败的尸体产生的气体和液体可能携带病菌
   - 长期接触尸体，心理压力大
   - 很多捞尸人有失眠、噩梦等心理问题

3. **道德风险：**
   - "挟尸要价"争议：2009年湖北荆州"挟尸要价"事件曾引发全国热议，捞尸人坐地起价、不交钱不捞尸
   - 但这只是个别现象，大多数捞尸人有底线
   - 也有捞尸人被家属讹诈的情况：捞上来了说不是，不给钱

4. **社会歧视：**
   - 因为职业特殊，很多人不愿意跟捞尸人打交道
   - 亲戚朋友疏远，连婚嫁都受影响
   - 很多捞尸人不愿对外人说自己的职业

### 2.5 灰色地带

1. **收费不透明：**
   - 没有统一收费标准，全靠双方协商
   - 容易出现"坐地起价"的情况
   - 也有"天价捞尸费"的新闻

2. **打捞权属问题：**
   - 哪些区域可以捞、哪些不能，规定不明确
   - 有时会和官方打捞队产生冲突

3. **尸体处理：**
   - 无名尸体怎么处理、保管费谁出，都是问题
   - 有些捞尸人会把无名尸体暂存在岸边，等家属认领

## 三、风水先生/阴阳先生

### 3.1 职业概述

**真实存在，但处于灰色地带。**

风水先生，又称"阴阳先生""风水师""地理先生"，是中国传统职业之一，主要为人看风水、选墓地、看宅基地、算八字、做法事等。

这个职业历史悠久，最早可追溯到商周时期的"卜筮"之官。经过几千年发展，形成了一套完整的理论体系（风水学），也催生了一个庞大的从业者群体。

**分类：**
- **阴宅风水**：专门看墓地、葬地
- **阳宅风水**：看住宅、办公场所
- **算命先生**：算八字、看相、测字
- **阴阳先生**：兼顾风水和法事，主要在农村地区
- **现代"风水大师"**：包装成"环境规划师""国学大师"，面向高端客户

### 3.2 真实工作内容与日常

**核心业务：**

1. **看风水：**
   - 阴宅：为逝者选择墓地，看"龙脉""穴位""朝向"
   - 阳宅：为住宅、商铺、办公楼看风水，指导布局
   - 使用工具：罗盘（罗经）、鲁班尺等

2. **算命/预测：**
   - 八字算命：根据出生年月日时推算命运
   - 看相：手相、面相
   - 测字、占卜、起名

3. **做法事/择日：**
   - 红白喜事择日（结婚、搬家、下葬等）
   - 开光、辟邪、化解"煞气"
   - 农村地区还负责主持葬礼、做"法事"

**真实日常：**
- 没有固定工作时间，客户随叫随到
- 上午看风水、下午算命，晚上可能还要做法事
- 收入来源：看风水费、算命费、法事费、卖风水物品（貔貅、八卦镜、五帝钱等）
- 收入差异极大：农村阴阳先生看一次风水几百到几千，"大师"级别的可能几十万甚至上百万

**从业者画像：**
- 年龄偏大，中老年人居多
- 很多是家传或师承，也有自学成才的
- 文化程度参差不齐，有真正研究《周易》的，也有纯骗子
- 口才普遍好，善于察言观色

### 3.3 行业规矩与黑话

**行规：**
1. **"五弊三缺"**：
   - 传说算命先生泄露天机会遭报应，犯"五弊三缺"（鳏、寡、孤、独、残；钱、命、权）
   - 真实性无法证实，但很多从业者相信，也用作收费高的理由

2. **"算卦不说破"**：
   - 说话留三分，不说太满，给自己留余地
   - 也有"天机不可泄露"的说法

3. **"不空卦"**：
   - 算命不能白算，一定要给钱，多少都行
   - 说是"不收钱就白送命"，其实是行规，保证收入

4. **"进门不骂门"**：
   - 到了人家家里，不能一进门就说人家风水不好
   - 要先说好话，再慢慢指出问题

**黑话/行话：**
| 行话 | 含义 |
|------|------|
| 堪舆 | 风水（书面语） |
| 点穴 | 找墓地穴位 |
| 寻龙 | 找龙脉 |
| 理气 | 根据方位、时间推算吉凶 |
| 峦头 | 地形地势 |
| 立向 | 确定朝向 |
| 化煞 | 化解凶煞 |
| 批八字 | 算命 |
| 看宅子 | 看阳宅风水 |
| 看坟地 | 看阴宅风水 |
| 老仙儿/大仙儿 | 对同行的尊称（北方） |
| 师傅/先生 | 通用称呼 |

### 3.4 真实风险

1. **法律风险：**
   - 纯算命看风水一般不违法，但如果涉及诈骗就另当别论
   - 利用封建迷信骗取钱财，可构成诈骗罪
   - 2025年多地警方打掉"风水大师"诈骗团伙，涉案金额动辄上千万
   - 有些"大师"号称能"改运""消灾"，实则骗钱

2. **信誉风险：**
   - 算得不准、看风水不灵，容易砸招牌
   - 靠口碑吃饭，一旦名声坏了就没生意了

3. **人身安全风险（较少）：**
   - 看风水经常要去偏僻的山上、野外，有一定危险
   - 偶尔会遇到客户不满意找麻烦的情况

4. **行业乱象：**
   - 骗子太多，真正懂行的少
   - "大师"遍地走，很多都是包装出来的
   - 收费混乱，从几十到几十万都有

### 3.5 灰色地带

1. **科学与迷信的边界：**
   - 风水学中有合理的部分（环境心理学、建筑学），也有迷信成分
   - 这个边界很难划清

2. **诈骗与"行业惯例"：**
   - 很多"风水物品"成本几块钱，卖几百上千
   - "消灾""改运"的说法，到底是心理安慰还是诈骗？

3. **从业者资质：**
   - 没有官方认证的"风水师"资格证
   - 什么人都能自称"大师"

## 四、入殓师/殡葬化妆师

### 4.1 职业概述

**真实存在，且正在逐步走向正规化。**

入殓师，又称"殡葬化妆师""遗体整容师""遗体防腐师"，是为死者进行遗体清洁、美容、防腐、整形的专业人员。

这个职业在古代叫"仵作"（但仵作更多是验尸的，类似法医），现代是殡葬行业的一个重要工种。因为常年与尸体打交道，普通人避之不及，所以显得很神秘。

**不同层级：**
- **殡仪馆正式员工**：有编制，正规培训，收入稳定
- **殡葬公司入殓师**：市场化运作，服务高端客户
- **民间"入殓师"**：农村地区的"死人化妆师"，没受过正规培训

### 4.2 真实工作内容与日常

**核心工作：**

1. **遗体接收与清洁：**
   - 接收遗体，进行登记、消毒
   - 为遗体清洗、穿衣、整理

2. **遗体整容/化妆：**
   - 为死者化妆，让逝者看起来安详、有生气
   - 修补因事故、疾病造成的遗体残缺
   - 难度高的需要缝补、填充、塑形

3. **遗体防腐：**
   - 注射防腐液，延缓遗体腐败
   - 特殊情况（如需要长期保存）需要更复杂的处理

4. **告别仪式服务：**
   - 协助家属举办追悼会、告别仪式
   - 确保遗体在告别仪式上状态良好

**真实日常（根据入殓师自述整理）：**
- 工作时间：早班6-7点就要到岗，因为告别仪式通常在上午
- 一天可能处理几具到十几具遗体，看殡仪馆规模
- 工作环境：常年在低温、消毒水味的环境中
- 收入：殡仪馆正式员工月薪5000-10000元，加上奖金可能更多；高端殡葬公司的入殓师收入更高，但也更累
- 很多人是护理、医学相关专业出身

**从业者画像：**
- 年轻人越来越多，很多是90后、00后
- 女性占比不低，甚至超过男性（女性更细心）
- 性格大多内敛、细腻，心理素质好
- 很多人选择这一行是因为想"给逝者最后的尊严"

### 4.3 行业规矩与禁忌

**行业讲究：**

1. **不能说"再见""一路走好"？**
   - 假的。这是外界对这个职业的误解。
   - 入殓师也会对家属说"节哀顺变""保重身体"，正常的安慰话都会说。

2. **不参加亲友的婚丧嫁娶？**
   - 半真半假。有些入殓师自己会主动回避，怕别人介意；但也有人正常参加。
   - 主要是社会偏见的问题，不是行规。

3. **遗体不能随意拍照？**
   - 真的。这是对死者和家属的尊重，也是职业操守。
   - 除非工作需要或家属同意，否则不能拍照。

4. **对遗体要尊重，不能说笑？**
   - 真的。工作时要严肃、认真，这是基本职业道德。

5. **工作后要洗手、换衣服？**
   - 真的。既是卫生需要，也有心理暗示的作用——"把工作留在单位"。

**黑话/行话：**
| 行话 | 含义 |
|------|------|
| 走了/去了 | 去世了（避讳说法） |
| 老人家/逝者 | 对死者的尊称 |
| 化妆/整容 | 遗体美容 |
| 穿衣服 | 为遗体穿衣 |
| 冷藏/冻着 | 遗体保存 |
| 告别 | 告别仪式 |
| 炉子 | 火化炉（避讳直接说） |
| 灰 | 骨灰 |

### 4.4 真实风险

1. **健康风险：**
   - 接触遗体可能感染病菌（特别是传染病死者）
   - 长期接触防腐液、消毒水等化学药品，对身体有影响
   - 长期在低温环境工作，易患风湿、关节病

2. **心理风险：**
   - 常年面对死亡，心理压力大
   - 容易产生职业倦怠、抑郁情绪
   - 很多入殓师需要定期心理疏导

3. **社会歧视：**
   - 别人知道职业后会疏远
   - 找对象难，很多人不愿意跟入殓师结婚
   - 连亲戚朋友都可能避讳
   - 很多入殓师对外人不说自己的职业

4. **职业伤害：**
   - 遗体搬运、整容过程中可能受伤
   - 高度腐败的遗体对感官刺激大，新人可能连续几天吃不下饭

### 4.5 灰色地带

1. **收费不透明：**
   - 殡葬行业收费高是普遍现象
   - 入殓服务、化妆、整容的价格差异很大
   - 有些不良商家利用家属悲痛心理"宰客"

2. **服务质量参差不齐：**
   - 正规殡仪馆还好，小的殡葬公司可能很不专业
   - 民间"入殓师"更是没有标准

3. **殡葬垄断：**
   - 很多地方殡仪馆是垄断经营
   - 服务费、骨灰盒、墓地价格虚高

## 五、职业讨债人/催收员

### 5.1 职业概述

**真实存在，且处于法律灰色地带。**

讨债人，又称"催收员""要账的""催债公司"，是专门帮债权人讨要债务的职业。

这个职业古已有之，古代叫"讨债鬼""要账的"。现代社会债务纠纷多，催生了庞大的催收行业。从合法的银行催收员，到游走在法律边缘的"职业讨债人"，再到暴力催收的黑社会性质组织，这个行业鱼龙混杂。

**分类：**
- **正规催收**：银行、金融机构的内部催收部门，或有资质的第三方催收公司，相对规范
- **职业讨债人**：专门帮人要账的个人或公司，收取高额佣金，手段游走在法律边缘
- **黑社会性质催收**：使用暴力、威胁、恐吓等手段讨债，属于违法犯罪

### 5.2 真实工作内容与日常

**主要讨债手段（从合法到违法）：**

1. **电话/短信催收**：
   - 最常见、最基础的方式
   - 不断打电话、发短信提醒还款
   - 正规公司有话术规范，但也有违规爆通讯录的

2. **上门催收**：
   - 到债务人家里、单位找人
   - 正规的会好好谈，不正规的就可能闹事
   - 有些会在债务人门口喷漆、写字、堵锁眼

3. **心理施压**：
   - 找债务人的亲戚、朋友、同事、领导
   - 到处散布欠债消息，让债务人颜面扫地
   - 跟踪、盯梢，制造心理压力

4. **灰色手段**：
   - 找社会闲散人员"摆场子"，不打人但吓唬人
   - 24小时跟着债务人，同吃同住（"软暴力"）
   - 用喇叭喊、拉横幅、泼油漆（这些已经违法了）

5. **暴力催收（违法）**：
   - 殴打、非法拘禁、威胁伤害家人
   - 这是黑社会性质组织的手段，警方严厉打击

**真实日常：**
- 工作时间不固定，债务人什么时候在什么时候去
- 每天就是打电话、找债务人、谈判
- 收入：按佣金算，一般是债务金额的20%-50%，难度越大佣金越高
- 要回来钱才能拿到提成，要不回来白干
- 很多人是社会闲散人员、刑满释放人员，也有律师、退伍军人转行做的

**从业者画像：**
- 男性居多，年轻气盛
- 能说会道，脸皮厚，心理素质好
- 社会经验丰富，三教九流都认识
- 有些人有前科

### 5.3 行业规矩与黑话

**行规（灰色地带的规矩）：**

1. **"欠债还钱，天经地义"**：
   - 这是讨债人的"信条"，也是他们自我合理化的理由
   - 但他们往往忽略了"合法讨债"的前提

2. **"不碰家人"**：
   - 有些讨债公司声称"祸不及家人"
   - 但现实中很多催收会骚扰家人，这条规矩更多是说说而已

3. **"见好就收"**：
   - 能要回多少是多少，不一定非要全额
   - 毕竟能拿回一部分总比一分都拿不回强

4. **佣金比例：**
   - 行业惯例：20%-50%不等
   - 死账、烂账佣金更高，可能对半分甚至更多
   - 一般是"要回来再付钱"，也有收前期费用的（多半是骗子）

**黑话/行话：**
| 行话 | 含义 |
|------|------|
| 要账/讨债/催债 | 追讨债务 |
| 老赖 | 欠钱不还的人 |
| 死账/烂账 | 很难要回来的账 |
| 上门 | 到债务人家里/单位去 |
| 爆通讯录 | 给债务人通讯录里的人打电话 |
| 摆场子 | 找一帮人去造势 |
| 软暴力 | 不打人但折磨人（跟踪、骚扰等） |
| 硬暴力 | 打人、拘禁等 |
| 点位 | 佣金比例（几个点就是百分之几） |
| 提成 | 佣金 |
| 回款 | 要回来钱 |
| 飞单 | 业务员私下接活，不走公司 |

### 5.4 真实风险

1. **法律风险（最大）：**
   - 暴力催收、非法拘禁、故意伤害，都是重罪
   - 软暴力（跟踪、骚扰、侮辱）也可能构成寻衅滋事罪
   - 2025年全国扫黑办继续打击"套路贷""暴力催收"，打掉大量涉黑涉恶催收团伙
   - 即使是"正规"催收，也可能因为侵犯公民个人信息、侮辱诽谤等被追责

2. **人身安全风险：**
   - 讨债容易激化矛盾，债务人可能狗急跳墙
   - 每年都有讨债人被债务人打伤甚至杀死的案例
   - 2024年江苏就发生过讨债人上门被债务人捅死的案子

3. **信誉风险：**
   - 在道上混，名声很重要
   - 要是"黑吃黑"（拿了钱不给债权人），以后就没法混了

4. **职业风险：**
   - 这行不稳定，今天有活明天没活
   - 年纪大了干不动，也没什么社会保障

### 5.5 灰色地带

1. **合法与违法的边界模糊：**
   - 正常的催款电话是合法的
   - 但什么时候算"骚扰"？边界很难把握
   - "软暴力"更是游走在法律边缘

2. **债务本身的合法性：**
   - 有些债务本身就是违法的（高利贷、赌债）
   - 帮人讨要违法债务，本身就可能违法

3. **催收公司资质：**
   - 很多催收公司没有合法资质
   - 打着"法律咨询""商务调查"的幌子做催收

## 六、私家侦探

### 6.1 职业概述

**真实存在，但在我国处于灰色地带——法律不承认"私家侦探"这个职业。**

我国法律没有赋予私家侦探调查取证的权力，私家侦探往往以"商务咨询公司""信息咨询公司""调查公司"的名义开展业务。

**主要业务类型：**
- **婚姻调查**：调查婚外情、出轨取证（最大宗业务）
- **商业调查**：竞争对手调查、商业间谍、打假维权
- **寻人找物**：寻找失踪人员、找回丢失物品
- **债务调查**：调查债务人财产线索
- **其他**：背景调查、行踪调查等

### 6.2 真实工作内容与日常

**主要工作（根据从业者自述整理）：**

1. **跟踪/盯梢：**
   - 最常见的工作，比如跟踪出轨的配偶
   - 需要长时间蹲守、开车跟踪、偷拍偷录
   - 讲究技巧，不能被发现

2. **调查取证：**
   - 收集证据，比如婚外情的照片、视频
   - 财产调查：查对方有多少房产、存款、车辆
   - 背景调查：查一个人的履历、社会关系

3. **寻人：**
   - 找失踪的人、欠钱跑路的人
   - 通过各种渠道打听、追踪

4. **商业调查：**
   - 调查竞争对手的商业情报
   - 打假：调查假货生产窝点

5. **打假维权：**
   - 帮企业调查制假售假窝点
   - 配合工商、公安打假

**真实日常：**
- 工作时间不固定，经常需要熬夜、早起
- 蹲守是常态，可能在车里待十几个小时
- 收入：按项目收费，婚姻调查一般几千到几万，商业调查更贵
- 风险高，被发现了可能挨揍
- 从业者很多是退伍军人、警察转行的，也有律师、记者

**从业者画像：**
- 男性居多
- 观察力强，记忆力好，心理素质过硬
- 懂点法律，知道什么能做什么不能做
- 社会关系广，三教九流都认识

### 6.3 行业规矩与黑话

**行规：**

1. **"不碰政治、不碰刑事案件"**：
   - 这是调查行业的红线
   - 政治案、刑事案件是警方的事，私家侦探碰了容易出事

2. **"只提供信息，不参与行动"**：
   - 很多调查公司声称只提供信息，不帮客户"捉奸""讨债"
   - 但实际上很多都做，只是嘴上不说

3. **"为客户保密"**：
   - 这是职业操守，也是立身之本
   - 客户信息绝对不能泄露

4. **"不见兔子不撒鹰"**：
   - 没拿到确凿证据，不轻易给客户结论
   - 也指没收到钱不干活

**黑话/行话：**
| 行话 | 含义 |
|------|------|
| 调查/干活 | 执行调查任务 |
| 目标/对象 | 被调查的人 |
| 盯梢/蹲点 | 跟踪监视 |
| 守坑 | 在一个地方蹲守 |
| 跟车 | 开车跟踪 |
| 拍东西 | 偷拍偷录 |
| 取货/拿东西 | 拿到证据 |
| 客户/雇主 | 委托人 |
| 点 | 位置、地点 |
| 线人 | 提供信息的人 |
| 擦边球 | 游走在法律边缘的业务 |
| 踩雷 | 碰到不该碰的，出事了 |

### 6.4 真实风险

1. **法律风险（最大）：**
   - 我国不承认私家侦探，调查行为本身可能违法
   - 偷拍偷录可能侵犯隐私权、肖像权
   - 获取公民个人信息可能构成"侵犯公民个人信息罪"
   - 2025年多地警方打掉非法调查公司，查处一批私家侦探
   - 即使是"婚姻调查"，取证手段不合法的话，证据在法庭上也不被采纳

2. **人身安全风险：**
   - 跟踪被发现了，可能被打
   - 调查黑社会、犯罪团伙，风险更高
   - 每年都有私家侦探被打伤的案例

3. **信誉风险：**
   - 调查行业鱼龙混杂，骗子很多
   - 收了钱不办事、故意拖延、伪造证据
   - 真有本事的侦探靠口碑吃饭

4. **职业风险：**
   - 工作不稳定，有上顿没下顿
   - 长期精神紧张，压力大
   - 对家庭生活影响大

### 6.5 灰色地带

1. **法律地位不明确：**
   - 没有"私家侦探"这个合法职业
   - 但市场需求真实存在，所以只能打擦边球

2. **证据合法性问题：**
   - 私家侦探取得的证据，法庭认不认？
   - 一般来说，只要不侵犯他人合法权益、不违反法律禁止性规定，就可以作为证据
   - 但这个边界很模糊

3. **行业混乱：**
   - 什么人都能开"调查公司"
   - 没有资质要求，没有行业规范
   - 诈骗、勒索、黑吃黑都有

## 七、职业打假人

### 7.1 职业概述

**真实存在，争议极大的职业。**

职业打假人，是指以牟利为目的，专门购买假货、问题商品，然后依据《消费者权益保护法》《食品安全法》等法律法规向商家索赔的人。

这个职业起源于1995年，"中国打假第一人"王海在北京买了假索尼耳机，然后依据《消法》"退一赔一"的规定索赔成功，从此催生了"职业打假人"这个行当。

**分类：**
- **"知假买假"型**：明知是假货还买，然后索赔——这是最典型的职业打假人
- **维权型**：本身是消费者，遇到假货后维权，慢慢变成职业的
- **"打假"为名敲诈型**：以举报、曝光相威胁，向商家索要钱财，涉嫌敲诈勒索

### 7.2 真实工作内容与日常

**主要工作：**

1. **找假货/问题商品：**
   - 逛超市、药店、网店，寻找假冒伪劣商品
   - 重点关注：食品、保健品、化妆品、电子产品、名牌商品
   - 看标签、看生产日期、看质检报告、比对真假

2. **购买：**
   - 发现目标后大量购买（买得多赔得多）
   - 保留好购物小票、发票、支付记录等证据
   - 有的会录像、公证，固定证据

3. **索赔：**
   - 先跟商家协商，要求"退一赔三"（消法）或"退一赔十"（食安法）
   - 协商不成，向市场监管部门投诉、举报
   - 还不行，就向法院起诉

4. **诉讼：**
   - 很多打假人常年跟法院打交道
   - 有的打假人一年能打几百场官司
   - 大部分案件以调解结案，商家赔钱了事

**真实日常：**
- 每天就是逛超市、逛网店、找假货
- 大量时间花在投诉、举报、打官司上
- 收入：靠赔偿金，做得好的年入几十万甚至上百万
- 但也有很多"新手"赚不到钱，甚至亏本

**从业者画像：**
- 什么人都有，下岗工人、农民、大学生、律师都有
- 懂点法律，熟悉《消法》《食安法》
- 细心，能发现一般人注意不到的问题
- 脸皮厚，不怕跟商家扯皮

### 7.3 行业规矩与黑话

**行规/潜规则：**

1. **"假一赔三""假一赔十"：**
   - 《消费者权益保护法》第五十五条：经营者提供商品或者服务有欺诈行为的，应当"退一赔三"，不足500元的按500元算
   - 《食品安全法》第一百四十八条：生产不符合食品安全标准的食品或者经营明知是不符合食品安全标准的食品，消费者除要求赔偿损失外，还可以向生产者或者经营者要求支付价款十倍或者损失三倍的赔偿金；增加赔偿的金额不足一千元的，为一千元
   - 这是职业打假人的主要法律依据

2. **"只打大，不打小"？**
   - 不一定。大超市、大品牌赔得起，但也难打
   - 小商家虽然钱少，但容易得手
   - 很多打假人专打超市里的食品、保健品

3. **"调货"：**
   - 发现某家店有假货，通知同行一起来买
   - 大家一起索赔，"共享资源"

4. **"私了"还是"打官司"：**
   - 大部分商家愿意私了，赔钱了事
   - 打官司费时间费精力，但赔偿有保障
   - 打假人一般先协商，不行再起诉

**黑话/行话：**
| 行话 | 含义 |
|------|------|
| 打假/维权 | 职业打假 |
| 货 | 问题商品、假货 |
| 目标 | 有问题的商家/商品 |
| 下单/进货 | 购买问题商品 |
| 索赔/要钱 | 要求赔偿 |
| 退一赔三/退一赔十 | 消法/食安法规定的赔偿标准 |
| 立案 | 起诉到法院 |
| 调解 | 庭前调解，商家赔钱 |
| 胜诉/败诉 | 官司赢了/输了 |
| 调货/串货 | 同行之间共享假货信息 |
| 碰瓷 | 故意找茬索赔（贬义） |
| 被反杀 | 打假不成反被商家告敲诈 |

### 7.4 真实风险

1. **法律风险：**
   - 最大的争议："知假买假"算不算消费者？能不能索赔？
   - 司法实践中有分歧：有些法院支持，有些不支持
   - 2023年最高法发布的《关于审理食品药品纠纷案件适用法律若干问题的规定》明确：因食品、药品质量问题发生纠纷，购买者向生产者、销售者主张权利，生产者、销售者以购买者明知食品、药品存在质量问题而仍然购买为由进行抗辩的，人民法院不予支持——也就是说，食品药品领域"知假买假"是受法律保护的
   - 但食品药品以外的领域（比如普通商品），"知假买假"能不能索赔，各地法院判法不一
   - 如果手段不当，可能构成敲诈勒索罪——比如以举报相威胁，索要超出法律规定的赔偿

2. **人身安全风险：**
   - 打假容易得罪人，商家可能报复
   - 有些打假人被商家打过
   - 特别是涉及假货窝点的时候，风险更高

3. **败诉风险：**
   - 不是每一场官司都能赢
   - 证据不足、法律适用问题，都可能败诉
   - 败诉了就血本无归

4. **职业风险：**
   - 随着监管越来越严，假货越来越少，打假空间也在缩小
   - 很多职业打假人转型了

### 7.5 灰色地带

1. **"打假"还是"碰瓷"？**
   - 同样是买假货索赔，有人说是"打假英雄"，有人说是"职业碰瓷"
   - 界限在哪里？公众和司法界都有争议

2. **牟利性打假的正当性：**
   - 支持方：职业打假人客观上打击了假货，净化了市场，是"民间啄木鸟"
   - 反对方：不是为了维权，而是为了赚钱，浪费司法资源，甚至构成敲诈勒索
   - 这个争论持续了二三十年，至今没有定论

3. **法律适用的不统一：**
   - 不同地区、不同法院对"知假买假"的判决不一样
   - 同样的案情，在A地能赢，在B地可能输

## 八、赏金猎人/追逃人员

### 8.1 职业概述

**在国外（如美国）是合法职业，在我国基本不存在合法的"赏金猎人"。**

美国的赏金猎人（Bounty Hunter），又称"保释 enforcement 人员"，主要工作是追捕保释期间逃跑的嫌疑人，抓到后可以从保释金中拿提成。

在我国，追捕逃犯是公安机关的权力，私人没有追捕的权力。但现实中存在一些类似的灰色职业：

**类似职业（中国语境下）：**
- **"线人"**：为警方提供线索的人，有奖励，但不是正式职业
- **"寻人公司"**：帮人找失踪的人、跑路的债务人
- **"商账追收"**：帮企业追讨债务，类似讨债公司
- **私家侦探的"找人"业务**：见前述私家侦探

之所以把"赏金猎人"列进来，一是因为公众从影视剧中听说过，对这个职业有神秘感；二是因为我国确实存在一些"灰色追逃"的现象。

### 8.2 真实工作内容（以美国赏金猎人为主，国内类似职业参考）

**美国赏金猎人的工作：**

1. **追踪逃犯：**
   - 接受保释公司委托，追捕保释期间逃跑的被告人
   - 通过各种渠道（线人、监控、社交网络）追踪逃犯下落

2. **抓捕：**
   - 找到逃犯后实施抓捕
   - 美国赏金猎人有一定的执法权（不同州规定不同）
   - 可以进入逃犯住所（部分州）

3. **押送：**
   - 把抓到的逃犯送回监狱或法院
   - 完成后从保释金中拿提成（一般是保释金的10%-25%）

**国内类似情况：**
- 公安机关悬赏通缉：提供线索抓获逃犯的，可获得悬赏金（几万到几十万不等）
- 这是"举报奖励"，不是"赏金猎人"职业
- 民间"追逃"更多是讨债、找人，属于私家侦探/讨债公司的业务范围

### 8.3 行业规矩与黑话

**美国赏金猎人相关：**
| 术语 | 含义 |
|------|------|
| Bounty Hunter | 赏金猎人 |
| Bail Bondsman | 保释担保人/保释公司 |
| Skip/Bail Jumper | 保释逃跑的人 |
| Bounty | 赏金 |
| Fugitive Recovery Agent | 逃犯追缉员（赏金猎人的正式称谓） |

**国内相关：**
| 术语 | 含义 |
|------|------|
| 悬赏通缉 | 公安机关发布的悬赏通告 |
| 线人/耳目 | 为警方提供线索的人 |
| 追逃 | 追捕逃犯 |
| 上网追逃 | 网上通缉 |
| 红色通缉令 | 国际刑警组织发布的通缉 |
| 捞人 | （贬义/灰色）通过关系把人保出来 |

### 8.4 真实风险

**美国赏金猎人的风险：**
1. **人身安全风险极高：**
   - 追捕的都是逃犯，可能有暴力倾向、有武器
   - 每年都有赏金猎人受伤甚至死亡
   - 2024年美国就有3名赏金猎人在抓捕时被枪杀

2. **法律风险：**
   - 执法权限有限，越权抓捕可能犯法
   - 不同州法律不一样，容易踩线
   - 误伤、误抓要承担法律责任

3. **职业风险：**
   - 工作不稳定，不是天天有活
   - 收入波动大

**国内情况：**
- 没有合法的"赏金猎人"职业
- 普通市民提供线索拿悬赏是合法的
- 但如果私自追捕、拘禁逃犯，可能构成非法拘禁罪
- 专业"追逃"更多是警方的事

### 8.5 灰色地带

国内的"追逃"灰色地带主要在：
1. **私家侦探/讨债公司的"找人"业务**——合法性存疑
2. **"捞人"骗局**：声称能帮人"捞出来"，实则诈骗
3. **线人奖励**：警方的线人制度本身是合法的，但具体操作中有灰色空间

## 九、文物修复师

### 9.1 职业概述

**真实存在，且正在走向正规化、专业化。**

文物修复师，是运用传统工艺和现代技术，对破损的文物进行修复、保护的专业人员。

这个职业古已有之，古代叫"裱画师""铜匠""玉匠"等，很多文物修复技艺是师徒相传的绝活。现代文物修复已经发展成一门专业学科，各大博物馆、文物机构都有专门的修复部门。

**分类（按修复对象）：**
- **书画修复**：古书画装裱、修复
- **陶瓷修复**：瓷器、陶器的修补、复原
- **青铜器修复**：青铜器的除锈、补配、做旧
- **玉器修复**：玉器的修补、抛光
- **古籍修复**：古籍、档案的修补、装裱
- **古建筑修复**：古建筑的修缮、保护
- **近现代文物修复**：油画、雕塑、家具等

### 9.2 真实工作内容与日常

**核心工作：**

1. **检测分析：**
   - 先对文物进行检测，分析材质、年代、病害情况
   - 使用各种仪器（显微镜、X光、光谱分析等）
   - 制定修复方案

2. **清洗：**
   - 去除文物表面的污垢、锈蚀、污染物
   - 不同材质用不同的清洗剂和方法
   - 非常考验耐心和技术

3. **修补/复原：**
   - 对破损的地方进行补配、粘接
   - 缺失的部分要补回去，还要跟原件协调
   - 讲究"修旧如旧"，但也要"可识别"（就是修过的地方要能看出来，不能乱补）

4. **加固/保护：**
   - 对修复后的文物进行加固处理
   - 做防腐、防氧化、防虫等保护处理
   - 让文物能保存更久

5. **建档：**
   - 修复前后拍照、记录
   - 建立修复档案

**真实日常：**
- 工作时间相对固定，朝九晚五（博物馆上班时间）
- 大部分时间坐在工作台前，低头干活
- 工作节奏慢，一件文物可能修几个月甚至几年
- 需要极强的耐心和专注力
- 收入：博物馆的修复师是事业编，工资不高但稳定，月薪几千到一万多；民间修复师收入差异大，大师级的收费很高

**从业者画像：**
- 性格沉稳、细心、有耐心
- 动手能力强，有艺术功底
- 很多是美院、考古、文物保护专业出身
- 也有很多是传统技艺师徒传承的

### 9.3 行业规矩与黑话

**行规/原则：**

1. **"最小干预"原则**：
   - 能不修就不修，能少修就少修
   - 不要过度修复，保留文物的历史信息

2. **"修旧如旧"原则**：
   - 修复后要跟原件风格协调，看起来像没修过一样
   - 但同时要"可识别"——近看要能看出哪里修过，不能造假

3. **"可逆性"原则**：
   - 修复用的材料要能去掉，以后有更好的技术还能再修
   - 不能用不可逆的材料把文物"焊死"

4. **"不改变文物原状"原则**：
   - 这是《文物保护法》的规定
   - 不能凭想象乱改、乱补

**黑话/行话：**
| 行话 | 含义 |
|------|------|
| 修文物/补文物 | 文物修复 |
| 上手 | 开始修这件文物 |
| 揭裱 | 把旧画的装裱揭下来 |
| 全色 | 补配后补颜色，让它跟原件一致 |
| 作旧/做旧 | 把新补的部分做旧，看起来有年代感 |
| 打料 | 调配修复材料 |
| 配补 | 补配缺失的部分 |
| 加固 | 加固文物本体 |
| 除锈 | 去除金属器的锈迹 |
| 建档 | 建立修复档案 |
| 开门 | （鉴定用语）真的、没问题 |
| 打眼 | （鉴定用语）看错了 |

### 9.4 真实风险

1. **技术风险：**
   - 修复失手，把文物修坏了
   - 这是最大的职业风险，也是最不能犯的错
   - 历史上有不少"修复事故"，把文物修得不伦不类

2. **健康风险：**
   - 修复用的化学试剂（溶剂、粘合剂、颜料等）可能有毒
   - 长期低头工作，容易得颈椎病、腰椎病
   - 长期在室内工作，缺乏运动

3. **职业风险：**
   - 成才慢，需要长期积累
   - 工资不高，特别是体制内的
   - 年轻人愿意学的越来越少，很多传统技艺面临失传

4. **法律风险：**
   - 修复文物需要资质，不能乱修
   - 如果修坏了珍贵文物，可能要承担法律责任

### 9.5 灰色地带

1. **"修复"还是"造假"？**
   - 修复中的"作旧""补配"，分寸很难把握
   - 有些不良修复师把修复过的文物当"全品"卖，这就是造假了
   - 还有专门修假货的，把假的修得像真的一样

2. **民间修复的资质问题：**
   - 体制内的文物修复师有规范
   - 民间修复市场鱼龙混杂，什么人都有
   - 修坏了文物，赔偿纠纷很多

3. **文物修复与文物买卖的边界：**
   - 有些修复师同时也做文物买卖
   - 这里面可能有利益冲突

## 十、典当行掌柜/当铺老板

### 10.1 职业概述

**真实存在，是一个古老而现代的行业。**

典当行，古称"当铺""质库""解铺"，是专门发放质押贷款的金融机构。人们把东西（黄金、珠宝、房产、汽车等）押给当铺，换一笔钱用，到期还钱赎回；到期不赎，东西就归当铺了。

这个职业在中国有一两千年的历史，现代典当行仍然存在，但已经跟古代当铺大不一样了。因为跟"钱""抵押""死当"这些概念挂钩，加上影视剧的渲染，典当行总给人一种神秘、甚至有点"黑"的感觉。

**现代典当行的主要业务：**
- **动产质押典当**：黄金、珠宝、手表、数码产品等
- **财产权利质押典当**：股票、债券、股权等
- **房地产抵押典当**：房产抵押
- **汽车典当**：汽车质押

### 10.2 真实工作内容与日常

**核心工作：**

1. **收当/验当：**
   - 客户拿东西来典当，先鉴定真假、估价
   - 这是最核心的能力——要看准东西值多少钱、能不能收
   - 黄金、珠宝、手表、汽车、房产，各有各的鉴定方法

2. **放款：**
   - 估价后跟客户协商当金（贷款金额）
   - 一般是估价的50%-70%
   - 办理手续、签合同、放款

3. **存管：**
   - 当品要妥善保管
   - 黄金珠宝放保险柜，汽车停车库，房产要办抵押登记

4. **赎当/续当/绝当：**
   - 客户到期还钱，赎回当品（赎当）
   - 到期没钱还，可以交利息续期（续当）
   - 到期既不赎也不续，东西就归当铺了（绝当）

5. **绝当品处置：**
   - 绝当的东西，当铺可以卖掉变现
   - 通过拍卖、零售等方式处理
   - 这也是典当行的重要收入来源

**真实日常：**
- 工作时间跟普通店铺差不多
- 每天就是接待客户、鉴定、估价、办手续
- 表面看起来清闲，其实考验眼力和经验
- 收入：主要是利息和服务费，还有绝当品的差价
- 老板的收入看典当行规模，小的一年几十万，大的上千万

**从业者画像：**
- 老板/掌柜：年纪偏大，经验丰富，看人准
- 鉴定师：懂行，有专业知识和经验
- 很多是家族生意，代代相传
- 现代典当行也有很多金融、法律专业的人

### 10.3 行业规矩与黑话

**传统当铺规矩（历史上）：**
1. **"三不当"**：
   - 神袍戏衣不当（怕来路不正，沾晦气）
   - 旗锣伞扇不当
   - 皮货无袱不当（怕掉毛说不清）
   - 不同当铺规矩不完全一样

2. **"折价三折"**：
   - 东西值十块，最多当三块
   - 古代当铺压价狠，现在规范了一些

3. **"朝奉"**：
   - 当铺里的掌柜、鉴定师叫"朝奉"
   - "徽州朝奉"很有名，徽商开当铺的多

4. **"当票"**：
   - 典当的凭证，写着当品、当金、期限、利息
   - 古代当票上的字很潦草，像"天书"，外人看不懂

5. **"死当/绝当"**：
   - 到期不赎，东西归当铺

**现代典当行黑话/行话：**
| 行话 | 含义 |
|------|------|
| 收当/接当 | 接收客户的典当物 |
| 赎当 | 客户还钱取回当品 |
| 续当 | 客户交利息，延长当期 |
| 绝当/死当 | 到期不赎，当品归当铺 |
| 当金 | 贷款金额 |
| 当期 | 典当期限 |
| 综合费 | 利息+服务费（典当行的主要收入） |
| 看货/验货 | 鉴定当品 |
| 估价 | 评估当品价值 |
| 折当率 | 当金占估价的比例 |
| 出货 | 把绝当品卖掉 |
| 硬货 | 黄金、珠宝等容易变现的当品 |
| 软货 | 不太好变现的当品 |

### 10.4 真实风险

1. **鉴定风险（最大）：**
   - 看走眼，收了假货、赝品
   - 这是典当行最大的风险，一笔亏了可能很多钱
   - 假黄金、假手表、假钻石是重灾区

2. **法律风险：**
   - 收到赃物（小偷来当偷来的东西）
   - 如果明知是赃物还收，可能构成掩饰、隐瞒犯罪所得罪
   - 即使不知情，赃物也要被追缴，当铺损失自担
   - 典当行有义务查验身份、询问来源

3. **经营风险：**
   - 绝当品卖不出去，资金周转不灵
   - 房地产、汽车等大宗当品，处置起来麻烦
   - 行业竞争激烈，越来越不好做

4. **信誉风险：**
   - 典当行靠信誉吃饭
   - 要是"杀价太狠""坑客户"，名声坏了就没生意了

### 10.5 灰色地带

1. **"高利贷"质疑：**
   - 典当行的综合费率（利息+服务费）看起来不低
   - 但典当行有当物质押，风险相对可控
   - 法律规定典当行利率不能超过银行同期贷款利率的4倍，综合费也有规定
   - 但有些不正规的典当行可能变相高息

2. **赃物风险：**
   - 典当行容易成为赃物销赃的渠道
   - 虽然规定要查验身份、登记，但总有漏洞
   - 这也是典当行被监管严格的原因之一

3. **"绝当品"的处理：**
   - 绝当品归当铺所有，当铺可以自由处置
   - 但有些绝当品价值远超当金，当铺赚差价是否合理？
   - 法律上是合法的，但情理上有争议
