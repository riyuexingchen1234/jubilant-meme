# Layer 1: 元规则
分析样本：第1、2、3章（开头）；第27、28、29章（中间）；第54、55、56章（结尾）

## 1. 叙事视角

- 采用第三人称全知视角，可以进入任何人物内心，但进入深度有限，主要靠行动和对话表现人物。
  原文引例：第28章杨威权衡是否出卖梅东时，用"他闭上嘴，心里权衡着"带过，不展开详细心理描写。

- 视角切换频繁，通常每章或每节切换一次人物视角，切换时没有明显过渡词，直接进入新场景。
  原文引例：第1章从劫匪视角切入，第2章直接跳到省厅高栋视角，中间没有过渡。

- 主要视角人物包括：张一昂、方超/刘直、周荣团伙、其他配角轮流作为视角人物。
  原文引例：第27章用旁白视角介绍"三江四贱"背景，然后切换到警方视角。

## 2. 叙事节奏

- 平均每章约7000-8000字，节奏极快，几乎没有废话。
  原文引例：第2章从举报信→决定派人→张一昂到任→叶剑死，一章之内完成多次剧情跳跃。

- 每章至少有一个小反转或笑点，章末必有钩子（悬念/反转/新事件）。
  原文引例：第3章结尾叶剑临死前写下"张一昂"的名字，把主角变成嫌疑人。

- 快慢节奏交替：紧张的案发现场/审讯场景用短句快节奏，背景介绍/人物关系用稍长段落。
  原文引例：第28章审讯杨威时，对话一句接一句，节奏极快；介绍"三江四贱"时段落较长。

## 3. 叙事距离

- 与主角张一昂的距离中等偏近，读者知道张一昂知道的，但也知道张一昂不知道的（比如劫匪线、周荣线）。
  原文引例：第1章读者先知道劫匪的计划，第2章才知道警方的行动，读者信息比主角多。

- 心理描写极浅，主要通过对话、动作、表情来体现人物心理，很少直接写"他想""他觉得"。
  原文引例：第29章王瑞军听张一昂讲故事时，用"回味咀嚼了好一阵，还是想不透"来表现，不用内心独白。

- 读者信息普遍比主角多，读者知道多线并行的真相，主角只掌握自己那条线的信息，产生戏剧性反讽。
  原文引例：第56章读者很早就知道郎博图的诡计，张一昂却靠错误的推理歪打正着。

## 4. 时间处理

- 基本按正序时间线叙事，但会用"一个半月前""三天前"等时间标记进行小幅度回溯。
  原文引例：第2章开头用"一个半月前"回溯高栋收到举报信的经过。

- 回忆/闪回使用极少，背景信息主要通过旁白直接交代或人物对话带出。
  原文引例：第27章"三江四贱"的背景全部用旁白一段说完，不用人物回忆。

- 时间流逝写法：用具体事件标记时间，不用"过了几天"这种模糊表达。
  原文引例：第27章用"三天前，林凯再次找上方老板"标记时间点。

## 5. 信息控制

- 悬念设置方式：读者比主角知道得多，但不知道全部真相，悬念来自"主角怎么发现真相"和"多线如何碰撞"。
  原文引例：第55章读者和警方都不知道郎博图怎么避开监控，悬念在于解谜过程。

- 伏笔手法：伏笔埋得浅，通常一两章内就回收，长线伏笔（如举报信）会反复提及。
  原文引例：第2章提到匿名举报信，到第56章才揭露是叶剑写的。

- 信息释放节奏：每章释放一到两个关键信息，同时抛出一到两个新悬念。
  原文引例：第54章审郎博图，释放出"周淇是陆一波女朋友"的信息，同时抛出"周淇去哪儿了"的新悬念。

- 从不提前剧透结局，但会通过黑色幽默让读者猜到"事情肯定不会按计划来"。
  原文引例：第1章方超计划周密，读者从刘直的表现就能猜到肯定会出岔子。
