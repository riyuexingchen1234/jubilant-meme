**调研日期：** 2026年6月30日
**信息来源：** 新闻报道、行业文章、从业者自述、论坛帖子、历史资料

## 一、核心问题："拉纤人/古玩中介"职业是否真实存在？

### 1.1 职业真实性确认

**真实存在。** 这是古玩行一个历史悠久的传统职业，在行业内有明确的称谓和行规。

根据多个来源交叉验证：
- **北方叫"对缝"，南方叫"拉纤"**（来源：腾讯阅读《从零开始的古玩人生》第63章、光明网《中国老行当之谜》）
- 官方称为"跑道儿"或"拉纤的"（来源：光明网2007年《中国老行当之谜》，引自聂鑫森著《中国老行当之谜》新华出版社）
- 现代语境下也叫"古玩经纪人"，但传统"拉纤人"与现代高端经纪人有区别
- 2001年《北京日报》报道，北京古玩城将"拉纤"与"砸浆""捡漏""搂货"等一同列入"文明经营者倡议书"，确认其为传统行规认可的行为

### 1.2 职业名称汇总

| 称谓 | 使用地区/场景 | 说明 |
|------|-------------|------|
| 拉纤 | 南方通用，古玩行传统行话 | 最传统的叫法，取"拉纤搭桥"之意 |
| 对缝 | 北方 | 意为"撮合双方，对上缝" |
| 跑道儿 | 老北京古玩行 | 强调"跑腿撮合" |
| 掮客 | 通用书面语 | 各类中介的统称 |
| 中间人/介绍人 | 通俗说法 | 直白易懂 |
| 古玩经纪人 | 现代高端市场 | 专业化、公司化运作 |

## 二、拉纤人的真实工作内容与日常

### 2.1 核心工作内容

根据收集到的信息，传统拉纤人的工作包括：

1. **信息撮合：** 掌握买卖双方信息，为卖家找买家，为买家找货
2. **鉴定估价：** 需具备基本眼力，能判断货品大致价值
3. **谈判议价：** 在双方之间斡旋，促成双方接受价格
4. **交易担保：** 传统拉纤人需为交易承担一定信誉担保责任
5. **保密隔离：** 传统规矩是不让买卖双方直接见面，避免"跳单"（绕过中介直接交易）

### 2.2 日常一天（不确定，缺乏详细第一人称自述）

**说明：** 关于传统拉纤人具体的"一天怎么过"，搜索结果中**缺乏详细的第一人称从业者自述**。现有信息多为小说描写或概括性描述。

根据有限信息推断：
- 传统拉纤人多混迹于古玩城、鬼市、茶馆等信息集散地
- 日常需要逛市场、看货、维系人脉
- 交易不固定，"三年不开张，开张吃三年"是古玩行常态
- 高端经纪人则需频繁参加拍卖会、拜访藏家、跨国飞行（如翟健民每年赴全球各地参加近百场拍卖会）

### 2.3 入行门槛

传统拉纤人门槛：
- **人品/信誉第一：** "人品先于眼力"是行内铁训（来源：搜狐"揭秘古玩界"系列文章）
- **眼力：** 能断代辨伪是基本功
- **人脉：** 需要长期积累买卖双方资源
- **入行需5-10年：** 从学徒做起，先在古玩店打工或跟师傅学习

现代高端古玩经纪人：
- 文博/考古/美术史专业背景优先
- 10年以上一线市场经验
- 覆盖藏家、拍卖行、古玩商的高端圈层网络

## 三、佣金比例

### 3.1 传统规矩："成三破二"

这是多个来源交叉验证的核心信息：
- **"成"指买方（买卖成了）：出成交价的3%**
- **"破"指卖方（货破了/出手了）：出成交价的2%**
- **合计5%佣金**

来源验证：
- 北京日报2001年6月30日报道："拉纤：甲要买古玩，乙要卖古玩，中间有人联络、说合，成交后中间人收取佣金，一般是买方出3%，卖方出2%"
- 钱币收藏界行话文章："拉纤：就是中间人、介绍人。中间人收取佣金，旧时一般是卖方出3%，买方出2%，俗称'成三破二'"
- 民国时期西安古玩市场研究："拉纤介绍者所获报酬称之为'打佣'，佣金5%——15%不等"
- 多本古玩题材小说均采用这一规矩（小说虽为虚构，但行规描述与现实一致）

### 3.2 现代佣金比例

- **私洽交易：5%-15%**
- **拍卖交易：10%-20%**（买卖双方各抽）
- **顶级经纪人：** 单笔佣金可达千万级（如李鉴宸、翟健民等）
- **普通从业者：** 年收入1-10万元，勉强维持

### 3.3 佣金风险

- 传统规矩中，买家一般会按规矩给佣金，卖家可能赖账
- "抄后路"：买卖双方绕过中介直接交易，是拉纤人最大风险
- 现代伪中介骗局：以"拉纤"为名收取前期费用（手续费、上架费、推广费等），实际不促成交易

## 四、拉纤人会遇到的人和事，真实风险

### 4.1 接触的人群

- **卖家：** 家道中落的世家子弟、藏家、铲地皮的（下乡收货者）、盗墓者（鬼货）、小偷（贼货）
- **买家：** 收藏家、投资者、企业家、古玩店老板、海外买家
- **同行：** 其他拉纤人、古玩商、鉴定专家
- **灰色地带：** 文物贩子、造假者、骗子

### 4.2 真实风险

1. **法律风险：**
   - 交易出土文物（鬼货）、被盗文物（贼货）可能涉嫌违法
   - 现代法律下文物交易有严格限制

2. **信誉风险：**
   - 介绍的货是假货，可能砸招牌甚至赔偿
   - "售赝必赔"是正规经纪人的行规

3. **跳单风险：**
   - "抄后路"或"下出笼"：买卖双方私下交易，中介费落空

4. **骗局风险：**
   - 做局：如2025年河北丁先生名画拍卖被骗案，掮客诸某设局导致画主自己花680万拍下自己的画
   - 伪中介诈骗：2021年海安警方破获的案件，诈骗分子冒充"古玩中间人""竞拍师"，以"拉纤"为由收取手续费、推广费，40余人诈骗200多人，涉案300多万

5. **人身安全风险（历史上）：**
   - 古代鬼市交易盗墓赃物，有遭遇亡命之徒的风险
   - 现代鬼市基本无此风险，但凌晨出行仍需注意安全

## 五、鬼市的交易规矩

### 5.1 鬼市的历史起源

- 起源于唐代宵禁制度下的夜间地下交易
- 清末民初达到鼎盛：家道中落的王公贵族、旗人凌晨变卖祖传宝物，不愿被人认出；盗墓者深夜销赃
- 因黎明前光线昏暗，人影绰绰如鬼影，故称"鬼市"

### 5.2 各地鬼市现状

| 城市 | 地点 | 开市时间 | 特色 |
|------|------|---------|------|
| 北京 | 潘家园、大柳树 | 周五夜场/凌晨3-4点 | 全国最知名，文玩杂项为主 |
| 景德镇 | 曙光路陶瓷古玩城 | 每周一、二凌晨3点 | 以瓷器、瓷片为主 |
| 广州 | 文昌北（周二凌晨）、光塔路等 | 凌晨0点-8点半 | 旧书、文玩，历史超百年 |
| 西安 | 古玩市场（如大唐西市周边） | 周末凌晨 | 陶瓷、瓦当、铜器 |
| 太原 | 南宫古玩市场 | 周末凌晨4-6点 | 综合性古玩 |
| 重庆 | 熊猫金街（防空洞） | 周六凌晨3-7点 | 战时旧物等 |
| 成都 | 送仙桥一带 | 不确定 | 传统古玩鬼市 |
| 郑州 | 淮河路古玩城（周末早市6点开始）、京广路漓江路（新鬼市卖菜） | 周末/深夜 | 淮河路是古玩早市，京广路是2022年疫情期间形成的蔬菜鬼市 |

**重要说明：** 现在很多所谓"鬼市"已经变成普通旧货市场或游客打卡地，真正传统意义上的鬼市已不多见。郑州淮河路古玩城是周末早市（6点开始），并非严格意义上的凌晨鬼市；而郑州京广路漓江路的"鬼市"是2022年疫情期间形成的蔬菜批发市场，与古玩无关。

### 5.3 鬼市核心规矩（多个来源交叉验证）

1. **照货不照人：** 手电筒只能照货品，不能照摊主的脸。这是保护卖家隐私的历史规矩，避免认出卖家身份。坏了规矩可能被骂甚至被拒售。

2. **看货不问来路：** 不问东西从哪来的，不问卖家身份。因为历史上鬼市货源复杂（家传宝物、盗墓赃物、小偷销赃等），问了犯忌。

3. **不问真假：** 不直接问"这是真的吗"，真假自负。买定离手，考验眼力。委婉说法是"看不好"（表示存疑）。

4. **买定离手，出门不换/不退不换：** 一手交钱一手交货，离开摊位后概不负责。"人走一抹脸，出门不认账"。

5. **别人上手的东西不抢：** 别人正在看的东西，要等对方放下、交易结束后才能问价。不能中途插话、抢货。

6. **观棋不语：** 别人交易时不插话、不评价。

7. **不随便拍照：** 尤其不能拍摊主的脸。

8. **价格用行话/暗语：** 传统交易在袖筒里掐指头谈价，或用黑话数字（见行话部分），避免旁人知道价格。现在部分鬼市仍有此遗风。

### 5.4 鬼市必备工具

- **手电筒：** 必备工具，专业手电是身份象征
- **放大镜：** 看细节、辨真伪
- **双肩包/布袋：** 装淘到的宝贝
- **现金：** 传统鬼市多用现金交易（现在也有移动支付）

### 6.4 数字暗语（历史上）

清末民初琉璃厂古玩贩子为躲避公安检查，曾有一套完整数字暗语：
- "么、按、搜、臊、歪、料、俏、笨、脚、勺"分别代表1-10

广州等地鬼市价格黑话：
- "1块钱"=100元
- "1毛钱"=10元
- "1个手指头"含义灵活，需看语境

## 七、古玩行业常见骗局

### 7.1 中介类骗局

1. **虚假拉纤/前期费用骗局：**
   - 以"帮你卖古董""联系买家"为名，收取鉴定费、手续费、上架费、推广费、出关费等
   - 2021年海安案例：诈骗分子开"拍卖平台"，要求交1500元手续费、1000元置顶费、900元资金证明费，实则不促成交易
   - 特征：**凡是交易前要求交各种费用的，基本都是骗局**

2. **拍卖做局（砸盘）：**
   - 2025年河北丁先生案例：掮客诸某谎称有首富买家，骗丁先生将石鲁名画从嘉德撤回转至上海嘉禾拍卖，安排假买家举牌，骗丁先生自己举牌托价，结果拍卖师直接落槌，丁先生花680万拍下自己保底1200万的画，价格被"锁死"在低位
   - 这种"砸盘"套路是：通过拍卖压低价格记录，迫使卖家低价出手

3. **鉴宝节目做局（背竹篓）：**
   - 小说《大鉴宝师》中提到的"背竹篓"：以鉴宝栏目为幌子，安排托儿做诱饵，遇见真品就招摇撞骗
   - 现实中也有类似的虚假鉴定机构

### 7.2 卖货类骗局

1. **埋地雷：** 造假者把仿品放到农民家里，编故事骗买家下乡"捡漏"
2. **杀猪：** 约好时间地点，专门把假货卖给特定目标
3. **讲故事：** 给假货编出身（"家传的""宫里出来的""工地挖的"）
4. **高仿做旧：** 各种做旧手法（酸蚀、入土、接底、后加彩等）
5. **钓鱼：** 摆一件真东西当诱饵，吸引买家后卖一堆假货
6. **托儿：** 安排人假装抢购、抬价

## 八、真实鬼市氛围：与小说/想象的差距

### 8.1 真实氛围

根据多篇记者实地探访（新民晚报景德镇鬼市、广州日报文昌墟、华商报西安古玩市场、大河报郑州古玩城等）：

1. **时间：** 凌晨2-4点开始，天亮（7-8点）结束/转成普通早市
2. **光线：** 昏暗，手电筒是主要照明工具
3. **声音：** 相对安静，没有大声吆喝，讨价还价低声进行
4. **人群：** 有真正的藏家、古玩商，也有游客、打卡者，还有骗子、托儿
5. **货品：** 真假混杂，真品极少，90%以上是仿品、新货、旧货，真正"捡漏"的概率极低
6. **氛围：** 既神秘又市井，有老炮儿也有新手，有人真淘宝，有人看热闹
7. **周边配套：** 天亮后路边常有卖早饭的（冷粉、油条、小鱼汤等），淘货的人顺便吃早餐

### 8.2 与小说/想象的差距

| 小说/想象 | 现实情况 |
|----------|---------|
| 遍地是宝贝，捡漏容易 | 真品极少，"捡漏"神话大多是传说或营销 |
| 神秘紧张，像谍战 | 现在多数已变成普通市场/游客打卡地，没有那么神秘危险 |
| 都是盗墓贼销赃的黑货 | 现在基本都是合法旧货、仿品，出土文物风险大且违法 |
| 交易惊险刺激 | 大部分时候是蹲在地上拿手电照瓷片、讨价还价，很平淡 |
| 拉纤人神通广大、手眼通天 | 普通拉纤人就是信息中介，赚点辛苦佣金；顶级经纪人确实厉害但极少 |
| 鬼市半夜开张天亮消失很神秘 | 潘家园等市场现在周五夜场客流可达2.5万，已是公开的旅游景点 |
| 袖筒掐价、黑话满天飞 | 现在基本都是正常说话、微信转账，黑话只有老玩家偶尔用 |
| 人人都是行家 | 棒槌（新手）占大多数，真正懂行的是少数 |

### 8.3 真实的"鬼市经济"

- 郑州淮河路古玩城：周末早市6点开始，持续了20年，摆摊商户多来自外地
- 市场生态：50%商户微盈利，40%亏损，只有10%赚钱（郑州古玩市场负责人郭华语）
- 西安大唐西市：2015年后市场萧条，不少古玩店改卖土鸡蛋、土特产、开小超市
- 马未都等大藏家确实早年在潘家园捡过漏，但那是80-90年代的事，现在信息透明，捡漏极难

## 九、"铲地皮/跑乡收货"真实情况

### 9.1 职业定义

- **南方叫"跑地皮"，北方叫"铲地皮"**
- 自己不开店，专跑农村、街巷收货，然后卖给古玩店、收藏家
- 是古玩流通链条的最底层，也是一线收货者
- 王世襄、马未都当年也跑过地皮

### 9.2 真实工作状态

根据一位盛泽"老铲"的第一人称自述（炒邮网论坛2025年帖子）：
- 每天清晨五点半出发，骑电动三轮车，穿行在乡镇老街
- 工具：放大镜、强光手电、泉谱（钱币书）、帆布包、收货样品
- 每天骑行近百里
- 已坚持二十余年，但现在年轻人不干这行了
- 每个人心里有一张"老物件地图"，惦记着哪户人家有什么东西
- 四时八节上门询问，有时会被撵、被放狗追
- 经常遭人白眼，世态炎凉
- 现在信息透明，人人都会上网查价格，捡漏越来越难
- 有时连续十天半个月一无所获叫"空军"

### 9.3 铲地皮的收货故事（真实案例）

- 明代黄花梨圈椅从农户柴房杂物堆里发现
- 咸丰元宝宝苏当百样钱从老铜匠铜料筐里挑出
- 清代石刻构件被乡民用来垫猪圈
- 王世襄五元从通县农村收黄花梨方桌，绑自行车上驮回北京
- 王世襄和马未都一起下乡，马未都为帮王世襄八元买雍正漆盘，自己二百元买了个花瓶

## 十、备选题材调研

### 10.1 二手回收/旧货店老板的真实日常

**真实生态：**
- **收入分化大：** 有人年净利润40万，有人连年亏损甚至倒闭
- **核心能力不是"懂货"，而是"建立货源渠道"：** 第一个生意可能亏钱，但为了拿到"第一顺位通知权"，即未来有货卖家第一个想到你
- **日常工作：**
  - 杭州阿杰（35岁二手杂货店）：每天中午12点忙到半夜，理货搬货、接电话讨价还价、上门收货，店有2000多个类目，背负几百万贷款，最近才收支平衡
  - 长沙"淡水鱼旧物"段先生：24小时无人看守，一周去一次，副业经营
  - 广州武楷斯（华工法学毕业）：8年打造1200平旧物仓，月入过万，5秒内判断物品工艺、材料、年代
  - 孙大勇（废品站8年）：开业头三月赔两千多，分不清塑料种类、铜铝被骗，慢慢学习后走上正轨
- **行业特点：**
  - 100个人入行，3个月走60个，半年剩15个，撑过1年的最多3个
  - 不是卖东西，是卖"信息差"和"时间差"
  - 年轻顾客多是打卡，真正买货的是店主、收藏家
  - 旧物店盈利难，很多与咖啡、酒馆结合多元经营
  - 也有灰色/擦边球：有人从公司倒闭、工厂淘汰中低价收设备配件拆开卖，利润丰厚

### 10.2 县城跑腿/代办的真实日常

**主要业务：**
- **政务代办：** 社保医保、户籍证件、营业执照、车辆审车——痛点最突出
- **医疗代办：** 挂号、取药、陪诊——老人需求大
- **生活代办：** 代取快递、代买东西、短途接送孩子、代排队
- **商务代办：** 文件代送、费用代缴、酒店车票预订
- **节日代办：** 代送礼、代采购年货（在外游子需求大）

**真实收入：**
- 代排队：每小时20-30元
- 代办事：每单50-100元
- 稳定后日均收入300-600元
- 政务代办员（村/居委会干部兼职）：每件0.5-4元补贴（古蔺县案例）

**真实日常：**
- 熟悉每条巷道、每个窗口要什么材料
- "收核办返录"五步流程，关键节点主动反馈
- 坚持"三不原则"：不承接无依据事项、不代行需本人到场的法定程序、不保管客户身份证原件
- 县城是熟人社会，本地人做有信任优势
- 注意：搜索结果中大量是代办平台招商文章，真实从业者第一人称自述较少

### 10.3 社区团购站长/小超市的真实日常

**真实工作：**
- 身兼数职：分拣员、社群运营、售后客服、提货点管理员
- 收入来自订单提成，一般低于10%
- 典型一天：上午发团购清单，中午截单，下午分拣打包，下班高峰居民自提

**真实收入：**
- 西安王红梅（小卖部+多多买菜）：每天约100单，每月额外收入约3000元，小店客流量增加
- 上海林菲（小超市+同程生活）：每月赚几百元，佣金越来越低
- 运城谢丽雪（60平副食店）：通过团购盘活濒临倒闭的小店，群成员从20人发展到500人
- 湖南农村袁宇（兴盛优选团长+开发）：发展新团长拿返点，月收入可达上万
- 农村团长竞争激烈，一个村可能有20多个自提点

**真实困境：**
- 佣金不断降低，平台"割韭菜"嫌疑
- 货物堆店里占地方，司机不帮忙卸货
- 老人要求送货上门
- 售后问题多（破损、不新鲜要赔）
- 担心被平台取代
- 也有违法案例：宁波10余名站长靠"仅退款"截留商品开超市，涉案40万被判刑

## 十一、调研总结与信息真实性说明

### 11.1 已确认的信息（多个来源交叉验证）

1. ✅ "拉纤人"职业真实存在，行话叫"拉纤""跑道儿""对缝"
2. ✅ 传统佣金比例是"成三破二"（买方3%，卖方2%，合计5%）
3. ✅ 鬼市核心规矩：照货不照人、不问来路、不问真假、买定离手
4. ✅ 古玩行话体系真实存在，"开门""打眼""捡漏""铲地皮"等术语有明确含义
5. ✅ "铲地皮/跑地皮"职业真实存在，工作辛苦，现在捡漏越来越难
6. ✅ 古玩中介骗局真实存在，前期费用诈骗、拍卖做局是常见套路
7. ✅ 现代鬼市已大量游客化、普通旧货市场化，与传统鬼市差距很大

### 11.2 不确定/信息不足的地方

1. ❓ 传统拉纤人具体的"日常一天"详细流程——缺乏第一人称自述
2. ❓ 郑州淮河路"鬼市"是否是严格意义上的凌晨鬼市——搜索结果显示它是周末早市6点开始，更接近古玩早市而非深夜鬼市；郑州真正的"鬼市"是2022年形成的蔬菜批发市场
3. ❓ 普通拉纤人的真实平均收入——只有"普通从业者1-10万"的笼统说法，缺乏具体个案
4. ❓ 传统鬼市中"袖筒掐价"等老规矩现在还有多少人用——大部分市场已不用，但部分老玩家可能保留
5. ❓ 县城跑腿代办从业者的真实第一人称故事——搜索结果多为招商广告，真实从业者自述少
