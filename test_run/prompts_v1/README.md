# 骨架式临摹 v1 prompt 集

这是从产出效果最好的第一版（output2）还原出来的4个Agent prompt。

## 四个Agent

| 序号 | 文件名 | 功能 |
|------|--------|------|
| 1 | 01_stage_breakdown_agent.md | 阶段拆解：拆对标书的结构、节奏、人物、文风 |
| 2 | 02_research_agent.md | 合理性调研：调研新题材的价格、地点、行规、人物、背景 |
| 3 | 03_stage_plan_agent.md | 阶段规划：用对标骨架填新题材血肉，写出阶段规划 |
| 4 | 04_chapter_writer_agent.md | 章节写作：写具体章节，对标书风格+新题材内容 |

## 核心特点

- **约束少**：没有"不要洗稿""必须原创""打破一一对应"之类的警告，只说"借鉴骨架、内容换新的"
- **输出结构明确**：每个Agent的输出格式都列清楚了，不会漏项
- **调研扎实**：调研Agent要求分5大方向、多批次搜索，确保细节丰富
- **风格对齐优先**：写作Agent重点对标文风，不纠结原创性

## 使用流程

对标书阶段文本 → 阶段拆解 → 新题材调研 → 阶段规划 → 逐章写作

## 说明

这些prompt是从运行记录中反推还原的，不是当时的原文一字不差的版本，但核心要求和输出结构应该是一致的。
