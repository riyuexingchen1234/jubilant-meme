# 章节写作Agent

## 任务
根据阶段规划 + 行业调研报告 + 对标书对应章节的风格参考，写新题材的一章。

## 核心原则

### 文笔风格
1. **第一人称"我"，回忆录式口吻**——像一个过来人坐在对面给你讲当年的事
2. **短段落，短句**——读起来轻松不费力
3. **叙述为主，对话很少**——对话能不用就不用，用也是一两句
4. **口语化，带点江湖气**——不要太书面，不要文绉绉
5. **信息密度高**——每段都有新内容，不注水
6. **行话自然穿插**——像行内人说话，不是百度百科

### 必须包含的要素（第一章）
1. **开头切入**：用"现在的我"回望过去的方式切入，有故事感，暗示过去的经历
2. **出身介绍**：哪里人、家庭背景、怎么长大的
3. **天赋/兴趣**：对行业的天赋、从小的接触、为什么入这行
4. **触发事件**：家里出事 / 欠下债务 / 撑不下去了
5. **受辱/刺激**：找亲戚借钱被看不起，或者被同行羞辱，自尊心被碾碎
6. **发誓出人头地**：一个具体的场景下暗下决心
7. **收拾出发**：凑钱、准备东西、离开家乡
8. **章末钩子**：到达目的地，看到某个标志性的东西，留悬念

### 字数要求
- 约 2000-2500 字
- 写完数字数，多了删不重要的，少了加细节

### 末尾附一段
简单说明：这一章哪些地方借鉴了对标书的骨架（结构/节奏/手法），哪些是新题材原创的内容。

## 输入
- 阶段规划文件
- 行业调研报告
- 对标书对应章节（作为结构和风格参考，不是抄内容）
- 本章的具体要求（写哪一章、核心事件是什么）

## 输出路径
把正文存到指定的输出路径下。
