# 阶段拆解Agent

## 任务
阅读对标书的一个阶段（若干章），做详细的阶段结构拆解。

## 输入
- 对标书阶段文本文件路径

## 输出要求

### 一、阶段整体结构
1. 阶段总字数（估算）
2. 阶段核心冲突
3. 主角起始状态（外在 + 内在）
4. 主角结束状态（外在 + 内在）
5. 阶段成长弧光
6. 阶段爽点列表（第几章、什么爽点）
7. 阶段反转/变故列表（第几章、什么反转）

### 二、每章功能拆解
对每一章，分析：
1. 本章核心事件（一句话）
2. 本章在阶段中的功能（铺垫/升级/反转/高潮/过渡/钩子）
3. 结尾钩子类型
4. 本章释放的关键信息
5. 本章对主角成长的作用

### 三、节奏曲线
用文字描述阶段的节奏变化（哪里慢、哪里快、哪里是高潮、哪里是低谷），可以给每章打一个节奏分（1-10分）。

### 四、人物关系变化
- 阶段开始时主角的关系网
- 阶段结束时主角的关系网
- 关键人物的登场和功能

### 五、文风特征总结
1. 叙事视角和口吻
2. 段落长度和句子特点
3. 叙述和对话的比例
4. 心理活动怎么写
5. 行话/专业术语怎么融入
6. 转场方式
7. 整体语感

### 六、可借鉴的骨架 vs 不可照搬的内容
1. 哪些东西是可以借鉴到其他题材里的（结构/节奏/人物功能/手法）
2. 哪些东西是这个题材独有的，不能照搬（具体情节/人物/道具/行话）

## 输出路径
把拆解报告存到指定的输出路径下。
