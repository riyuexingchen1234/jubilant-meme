# 第1章 离家

我在瑞丽红木圈混了十五年，见过一夜暴富的，也见过倾家荡产跳瑞丽江的。

这行里有句话，叫"一刀穷一刀富，一刀穿麻布"。说的就是赌木。

前几年有记者采访我，问我怎么看现在的红木市场。我跟他说，别看现在海南黄花梨炒到上万一斤，越南黄花梨一天一个价，这行当里的水，比瑞丽江还深。

我十六岁跟木头打交道，十八岁只身闯瑞丽，从木雕学徒干起，后来成了瑞丽圈子里小有名气的"小神眼"，再后来……算了，那些都是后话。

就从头说起吧。

我叫林青峰，福建莆田人。

我们莆田人做木雕是祖传的手艺，仙作的名头，在全国红木家具圈里响当当。我们林家祖上三代都是雕花匠，到我爷爷那辈，在莆田涵江开了个小木雕铺，叫"林记木坊"。

我爹是家里独子，本来该接爷爷的班，可他嫌做木雕来钱慢，九十年代末跟着人去云南倒木材，结果在景洪到昆明的路上出了车祸，连人带车翻下了山。

我娘知道消息后，不到半年也走了，扔下刚满三岁的我。

爷爷没说过什么怨天尤人的话，就把我拉扯大，教我认木头、学雕花。

老话说隔辈亲，这话一点不假。我小时候淘，爬树掏鸟窝，下河摸鱼，没少挨爷爷的揍。但只要一坐到木料前，拿起刻刀，我就跟换了个人似的，能坐一下午不动窝。

爷爷说我是天生吃木头这碗饭的。

我对木头确实有一种说不上来的敏感。同样是花梨木，我闭着眼摸两下、闻一闻，就能分出海南的还是越南的，心材多还是边材多。爷爷说这叫"木缘"，是老天爷赏饭吃。

他把祖传的一本"辨木诀"手抄本传给了我，封皮都磨破了，里面写满了各种木头的特征、产地、辨伪方法。我没事就翻，倒背如流。

那时候我以为，我这辈子就守着爷爷的木雕铺，安安稳稳做个雕花匠，也挺好。

直到我十八岁那年。

爷爷在料场搬料的时候摔了一跤，中风偏瘫，躺到了床上。

更要命的是，前几年爷爷看好红木行情，借了三万多块钱囤了一批大红酸枝料，想着等涨上去再出手。结果08年金融危机，红木价格跌得一塌糊涂，那批料砸手里了。

债主王老板三天两头上门逼债。

我记得很清楚，那天是农历六月初六，天热得像个蒸笼。王老板带着两个小弟找上门，一脚踹开了木雕铺的大门。

"老林头，钱什么时候还？三万块，拖了快两年了！"

爷爷躺在里屋的床上，嘴歪眼斜，话都说不利索，只能呜呜地哼。

我挡在床前，攥着拳头说："王老板，再宽限些日子，我爷爷病倒了，等他好点我们想办法。"

"想办法？"王老板冷笑一声，伸手就去扒拉货架上的木雕，"就这些破木头玩意儿？一件能卖几个钱？我告诉你林青峰，今天不还钱，我就把你这铺子里的东西全拉走抵债！"

他手下两个小弟上来就搬东西。

我冲上去拦，被其中一个推了个跟头，额头磕在桌角上，破了皮，血流了一脸。

王老板蹲下来，拍着我的脸说："小子，别怪我不客气。欠债还钱天经地义。你爷爷这老东西当年囤料的时候怎么不想想有今天？我跟你说，给你一个星期，再拿不出钱，我就把这铺子给你封了！"

说完，他踹翻了一个花架，带着人走了。

我坐在地上，看着满屋子狼藉，看着床上爷爷浑浊的眼泪，咬着牙，把嘴唇都咬破了。

三万块。

那时候莆田普通工人一个月工资也就一千多块，三万块对我们家来说，就是天文数字。

我想到了大姑。

大姑是爷爷的大女儿，嫁到了仙游，大姑父在当地开了个红木家具厂，生意做得不小，听说资产几百万。

当天下午我就坐车去了仙游。

大姑见了我，叹着气塞给我五百块钱，说这是她体己钱，让我先拿着给爷爷抓药。

我没接，我说我要借三万。

这时候大姑父从外面回来了，一听我要借三万，当时脸就拉下来了。

"三万？你小子做梦呢？"他坐在沙发上，跷着二郎腿，点了支烟，"你爷爷那老糊涂，07年行情好的时候不套现，非要囤着等涨价，现在套牢了，想起找我来了？"

"姑父，我爷爷确实是没办法了……"

"没办法？"大姑父吐了个烟圈，斜着眼看我，"我跟你说林青峰，这钱我不能借。不是我不帮你们，是帮了也白搭。你看看你，书不好好念，天天跟木头打交道，雕那些破玩意儿能挣几个钱？你们林家啊，就是烂泥扶不上墙，一代不如一代！"

"你说我行，别说我爷爷！"我腾地一下站起来。

"怎么着？我说错了？"大姑父也站了起来，声音比我还大，"你爹当年就是个败家子，放着好好的手艺不学，非要去倒木材，结果把命都搭进去了！你呢？我看你也好不到哪去！一个破木雕铺，一个瘫老头子，还欠着三万块外债，我要是借你们钱，那就是肉包子打狗——有去无回！"

大姑在旁边抹眼泪，拉着大姑父的胳膊让他别说了。

我站在那里，浑身发抖。

从仙游回来的路上，我走了三个多小时，六月的太阳晒得我头皮发麻，可我一点都不觉得热。

大姑父的话，像针一样扎在我心上。

烂泥扶不上墙。

败家子。

我攥着拳头，指甲嵌进肉里，渗出血来。

我在心里发誓：我林青峰，一定要挣到钱，一定要把债还清，一定要重振林家木雕，一定要让所有看不起我们家的人，都闭嘴！

回到家，我收拾了东西。

一个蓝布包，里面装着爷爷的"辨木诀"手抄本，还有几件我自己雕的小玩意儿——一串花梨木手串、一个紫檀小把件、一尊黄杨木观音摆件。

这些是我全部的家当。

还有两千三百块钱，是爷爷偷偷塞给我的，说是他的棺材本，让我拿着当路费。

我要去瑞丽。

我听行里的老辈人说，云南瑞丽是红木的天堂，遍地是黄金，缅甸的木材从那边进来，海南黄花梨、越南黄花梨、大红酸枝、小叶紫檀，什么料都有，只要你有眼力，就能挣大钱。

那年是2010年，红木行情刚从08年的低谷里爬出来，越南黄花梨涨得最凶，一天一个价。

我跟爷爷说，我要去瑞丽闯一闯，挣了钱就回来给他治病，把债还清，把林记木坊重新开起来。

爷爷躺在床上，说不出话，只是拉着我的手，眼泪一个劲地流。

农历六月十九，观音菩萨成道日，我走的那天。

莆田没有直达瑞丽的车，要先坐大巴到昆明，再从昆明转车到芒市，再从芒市坐车到瑞丽。全程两千多公里，要走三天两夜。

为了省钱，我买的最便宜的硬座大巴，票价比卧铺便宜一半还多。

车上人挤人，空气里弥漫着脚臭味、泡面味和汗味。我抱着蓝布包，靠在车窗边，一路没怎么合眼。

那是我第一次出远门。

以前我最远只到过莆田市区。

车过了泉州，过了厦门，往广东方向开。窗外的景色从熟悉的闽南红砖厝，变成了陌生的群山和隧道。

我脑子里翻来覆去就是大姑父说的那些话，还有王老板踹门的样子。

我跟自己说，林青峰，你这次出去，不混出个人样来，就别回来。

第三天下午，车终于到了瑞丽。

一下车，热浪扑面而来，比莆田还热，空气里有股子说不上来的味道，像是木头，又像是香料，还有点淡淡的花香。

瑞丽的天很蓝，云很低，路边的棕榈树叶子又大又绿，街上到处是穿着傣族裙子的姑娘，还有不少缅甸人，说着我听不懂的话。

我站在车站门口，有点发懵。

这就是瑞丽？

这就是传说中遍地黄金的红木之都？

我摸了摸兜里的钱，来的时候两千三，路上吃饭坐车花了一千四，现在兜里只剩下不到九百块。

九百块。

在这个陌生的城市，我能站住脚吗？

我不知道。

但我知道，我已经没有退路了。

我把蓝布包往怀里抱了抱，抬头看了看远处的高楼，深吸了一口气，迈开步子往城里走去。

那一年，我十八岁。

身无分文，一无所有。

只有爷爷的辨木诀，和一双能识木头的眼睛。

## 写作说明

### 1. 对标书第一章结构节点清单（共8条）
1. **回忆录框架开头**——"我"出狱后在大理开超市，以过来人口吻引入回忆
2. **出身背景介绍**——东北漠河农村，无父无母，奶奶养大，学习差
3. **入行起因铺垫**——看电视寻宝节目入迷，买书自学，开始收铜钱
4. **核心触发事件**——奶奶摔断腿没钱治，去大姑家借钱
5. **羞辱与立誓**——被大姑父骂"扫把星""破落户"，发誓出人头地，辍学
6. **筹备启动资金与货源**——用剩下的钱收了11件瓷器+200多铜钱
7. **离家上路过程**——借拉杆箱、坐火车去北京，第一次出远门
8. **结尾钩子**——到达北京，身上只剩不到一百块，悬念留尾

### 2. 红木版第一章结构节点清单（共8条）
1. **回忆录框架开头**——"我"在瑞丽红木圈混了十五年，见过暴富也见过跳楼，以过来人口吻引入回忆
2. **出身背景介绍**——福建莆田木雕世家，父母运木材车祸去世，爷爷养大，有识木天赋
3. **入行起因铺垫**——从小跟木头打交道，爷爷传"辨木诀"，本想安稳做雕花匠
4. **核心触发事件**——爷爷中风病倒，木雕铺欠三万外债，债主王老板上门逼债打人
5. **羞辱与立誓**——去大姑家借钱被大姑父骂"烂泥扶不上墙""败家子"，发誓重振家声
6. **筹备启动资金与货源**——带爷爷的辨木诀手抄本+三件木雕小件+两千三百块棺材本
7. **离家上路过程**——坐三天两夜硬座大巴去瑞丽，第一次出远门
8. **结尾钩子**——到达瑞丽，身上只剩不到九百块，悬念留尾

### 3. 本章实际字数
约2450字（不含写作说明部分）

### 4. 本章写得最好的地方
对比标书的结构还原度很高，从回忆录框架、出身背景、触发事件、借钱受辱、立誓离家、上路过程、结尾钩子，每个节点都精准对应，同时把红木行业元素（辨木诀、仙作、花梨紫檀、大红酸枝、瑞丽市场）自然融入，没有生硬堆砌。

### 5. 本章可能还有不足的地方
行业细节主要集中在木雕和木材识别方面，赌木和市场交易的行话还没怎么展开（因为是第一章，铺垫期可以理解），后续章节需要加大行业术语的密度。另外，主角的天赋展示可以更具体一些，比如加一个小时候辨木的具体例子。
