# 红木风云·第一阶段（1-10章）完整规划

## 一、阶段整体规划

### 1. 阶段名称
**初入瑞丽：从木雕学徒到赌木新人**

### 2. 阶段核心冲突
主角林青峰出身福建莆田木雕世家，爷爷病倒、木雕铺欠债，18岁的他怀揣爷爷的"辨木诀"和仅剩的两千块钱，孤身闯荡云南瑞丽红木市场。本想靠自己识木的天赋做正经生意翻身，却接连遭遇被骗摊位费、被料商压价、随身积蓄被偷等现实毒打，走投无路时被瑞丽"木王"陈德彪救下，引入灰色地带的赌木行当。第一次参与赌大料就遭遇"空心料""被人做过手脚"等重重变故，最终在险境中凭借天赋识破骗局、赌涨成功，赚到第一桶金的同时，也彻底踏入了红木这个疯狂又迷人的行业。

### 3. 主角起始状态（外在 + 内在）
**外在：**
- 18岁福建莆田少年，木雕世家出身，从小跟木头打交道
- 爷爷病倒，木雕铺欠了三万多外债
- 身上只剩两千多块钱（爷爷偷偷塞的棺材本）
- 第一次出远门，孤身一人到瑞丽
- 穿着朴素，社会经验几乎为零
- 带着一个布包，里面是爷爷的"辨木诀"手抄本和几件自己雕的小把件

**内在：**
- 自尊心极强，被债主上门羞辱后发誓要挣钱还债、重振家声
- 对木头有天生的敏感度，能凭手感、气味、纹路判断木材好坏
- 满脑子想的是靠手艺和眼力吃饭，认为赌木是歪门邪道
- 天真、冲动、不服输，相信靠自己的手艺能在瑞丽站稳脚跟
- 对未来充满憧憬但又极度迷茫，不知道红木行业的水有多深

### 4. 主角结束状态（外在 + 内在）
**外在：**
- 加入陈德彪的"德盛号"料场，职位是学徒/帮眼（最底层）
- 第一次参与赌大料就赌涨成功，一根1.2吨的越南黄花梨半赌料开出满格心材
- 认识了女孩依晴（傣族），为保护她被地痞打伤头部
- 从一无所有变成有组织、有来路钱的"圈内人"
- 在瑞丽红木圈子里小有名气，被人称为"小神眼"

**内在：**
- 从单纯想"靠手艺赚钱"变成已经踏入灰色赌木行当，三观开始被行业重塑
- 经历了绝望→重生→惊喜→恐惧的心理过山车
- 对红木行业的认知从零到有，开始接触行规、黑话、套路
- 仍然保留着少年的正义感和自尊心（为依晴出头）
- 对"木头"的理解从单纯的工艺材料变成了"能让人一夜暴富也能让人倾家荡产"的疯狂商品

### 5. 阶段成长弧光
**第一阶段：满怀希望的追梦少年**
→ 带着爷爷的辨木诀和全部家当闯瑞丽，相信靠手艺和眼力就能翻身

**第二阶段：现实毒打，跌落谷底**
→ 被骗摊位费、被料商压价、露宿街头、钱被偷，甚至想跳瑞丽江大桥自杀

**第三阶段：绝处逢生，踏入歪路**
→ 被陈德彪救下，加入德盛号料场，从学徒帮眼干起，接触赌木行当

**第四阶段：初入险境，见识世面**
→ 第一次参与赌大料，遭遇空心料、被人做过手脚等变故，亲眼见证"一刀穷一刀富"的疯狂，对行业有了真实认知

**第五阶段：意外邂逅，人性底色**
→ 帮眼送货时偶遇依晴，为其出头被打伤，展现出主角本性善良、有正义感的一面

## 二、每章详细规划（共10章）

### 第1章 离家
**1. 本章标题：** 离家

**2. 本章核心事件（一句话）：** 主角林青峰自述出身背景，因爷爷病倒木雕铺欠债，借钱被债主羞辱，辍学当木雕学徒，带着爷爷的辨木诀和几件木雕小件离家闯荡瑞丽。

**3. 本章在阶段中的功能：** 铺垫 + 钩子
- 交代主角的出身、动机、性格底色
- 建立"一定要出人头地、重振家声"的核心驱动力
- 结尾钩子：孤身一人到瑞丽，身上只剩不到一千块

**4. 主要场景（2-3个）：**
- 莆田老家木雕铺（爷爷病倒、债主上门）
- 大姑家借钱（被大姑父羞辱）
- 从莆田到瑞丽的长途汽车（第一次出远门）

**5. 出场人物：**
- 林青峰（主角，"我"）
- 爷爷（精神支柱、木雕技艺传人）
- 大姑父（羞辱者、动机触发器）
- 大姑（亲情、无奈）
- 债主王老板（上门逼债）

**6. 本章释放的关键信息：**
- 主角身世：福建莆田人，木雕世家，父母早逝（运木材车祸去世），爷爷养大
- 动机：被大姑父羞辱"败家子、烂泥扶不上墙"，发誓要挣钱还债、重振林家木雕
- 技能：从小跟木头打交道，有识木天赋，对纹路、密度、产地有天生敏感，爷爷传了"辨木诀"
- 启动资金：两千三百块（爷爷偷偷塞的棺材本），几件自己雕的木雕小件（花梨木手串、紫檀把件、黄杨木摆件）
- 目的地：云南瑞丽（听说那边红木生意好做，遍地是黄金）
- 时代背景：2010年中，红木价格暴涨，海南黄花梨已经上天，越南黄花梨正在疯涨

**7. 结尾钩子：**
处境悬念型——第一次出门的福建少年，身无分文，能在瑞丽这个疯狂的红木市场站稳脚跟吗？

**8. 本章对主角成长的作用：**
- 确立核心性格：自尊心强、不服输、有手艺、有天赋
- 完成"上路"的仪式，从静态背景进入动态剧情
- 埋下"父母运木材去世"的伏笔，与红木行业形成宿命般的呼应

---

### 第2章 卖货
**1. 本章标题：** 卖货

**2. 本章核心事件（一句话）：** 主角到瑞丽红木市场卖木雕小件，被骗摊位费、被料商压价、露宿ATM机，遭遇一连串现实毒打。

**3. 本章在阶段中的功能：** 低谷 + 铺垫
- 连续打压主角，将其逼入绝境
- 展现红木行业的残酷和欺生
- 为后续"走投无路入赌木行"做铺垫

**4. 主要场景（2-3个）：**
- 华丰市场（被骗摊位费、被打）
- 汇昌红木批发市场（被料商压价羞辱）
- 银行ATM机（露宿、大妈送米线）

**5. 出场人物：**
- 林青峰（主角）
- 光头摊主（骗摊位费、打人，社会毒打代表）
- 汇昌料场李老板（压价、羞辱福建人手艺）
- 傣族大妈（送米线，人间善意点缀）

**6. 本章释放的关键信息：**
- 瑞丽红木市场规则：摊位费贵、好位置要托关系、料场老板说了算
- 红木行业压价套路：老板故意贬低手艺、贬低材质，给价极低
- 主角性格：年轻气盛，受不了侮辱，宁可不卖也不受气
- 社会善意：傣族大妈送米线（人间温暖的点缀）
- 行业行话初体验："满彻""全红木""心材""边材"等基础术语

**7. 结尾钩子：**
希望曙光型——山穷水尽时碰到老头指路，姐告边贸市场有免费摊位，那边人傻钱多。

**8. 本章对主角成长的作用：**
- 社会第一课：现实比想象残酷，书本知识和手艺不够用
- 自尊心被反复碾压，但内心那股劲没散
- 从"我手艺好就能卖钱"的盲目自信变成"我该怎么办"的现实焦虑

### 第3章 翻身
**1. 本章标题：** 翻身

**2. 本章核心事件（一句话）：** 主角在姐告边贸市场摆地摊大获成功，被张老板一枪打收走全部木雕小件，净赚三万八，可当晚钱就被偷了，绝望到想跳瑞丽江大桥。

**3. 本章在阶段中的功能：** 高潮 + 反转 + 钩子
- 前半段是第一个小高潮（扬眉吐气）
- 后半段急转直下，跌到更深的谷底
- 结尾留钩子：被神秘老头拍下肩膀

**4. 主要场景（2-3个）：**
- 姐告边贸市场（摆摊大卖、一枪打包圆）
- 瑞丽江大桥（手持巨款大喊、宣泄情绪）
- 火车站小旅馆（钱被偷、跳桥轻生）

**5. 出场人物：**
- 林青峰（主角）
- 张老板（一枪打包圆的贵人、爽点制造者）
- 竞价的王老板（制造竞价氛围）
- 小旅馆老板娘（偷钱嫌疑人）
- 神秘老头（结尾出场，领路人雏形）

**6. 本章释放的关键信息：**
- 姐告边贸市场：自由贸易区，人流大，红木交易活跃，好卖货
- 行业黑话："一枪走"/"包摊"/"全端"——全部买走
- 主角性格：讲诚信（说好的价不坐地起价）
- 火车站小旅馆乱象：偷窃严重，警察也管不了
- 主角的脆弱：少年心智不成熟，遇到挫折就想轻生
- 时代背景：2010年红木市场火爆，只要有好货不愁卖

**7. 结尾钩子：**
人物出场悬念型——拍肩膀的是谁？能救主角吗？

**8. 本章对主角成长的作用：**
- 经历了"大喜→大悲"的极端情绪波动
- 证明了自己的眼光和手艺，但也暴露了社会经验不足
- 被推到人生悬崖边，为后续"入赌木行"提供合理性

### 第4章 入伙
**1. 本章标题：** 入伙

**2. 本章核心事件（一句话）：** 陈德彪救下想自杀的主角，邀其入伙德盛号料场，介绍红木行业格局和赌木行当，主角正式入行，第一趟活是去缅甸克钦邦看一批越南黄花梨大料。

**3. 本章在阶段中的功能：** 世界观展开 + 转折点
- 从"正经木雕生意"切换到"赌木行当"，打开新世界
- 交代行业背景、门派分工、行规黑话
- 完成主角的身份转变：从木雕学徒→赌木学徒

**4. 主要场景（2-3个）：**
- 瑞丽江大桥边（被救、受邀入伙）
- 德盛号料场（参观、了解行业）
- 陈德彪办公室（详谈行业格局、分工）

**5. 出场人物：**
- 林青峰（主角）
- 陈德彪（陈把头/木王，领路人、师傅、德盛号老板）
- 阿财（陈德彪的跟班/司机，前期龙套）

**6. 本章释放的关键信息：**
- 红木门派：福建帮（仙作、工艺好）vs 浙江帮（东阳、木雕好、敢赌）vs 广东帮（中山大涌、产能大、务实）
- 料场分工：把头（老板、找料、看料）、买手/帮眼（帮着看货、把关）、开料师傅（赌料切料）、搬运工、后勤
- 行话：全赌/半赌/明料、开窗/刨底、心材/边材/格、沉水料、一枪走、捂盘、帮眼
- 陈德彪：陈把头，瑞丽"木王"之一，摸过上万根料，眼光毒辣
- 主角职位：帮眼学徒（最底层，钱最少，但比打工强）
- 行规：赌输不认人、买定离手、不买不问价、看人不看货

**7. 结尾钩子：**
行动预告型——明天就出发，去克钦邦看一批越南黄花梨大料，准备赌一把大的。

**8. 本章对主角成长的作用：**
- 彻底改变人生轨迹，从正经手艺人转向灰色赌木行当
- 从"个体户"变成"团伙成员"，有了组织和师傅
- 眼界被打开，知道了"三万八就是鸡毛"的世界

### 第5章 下铲
**1. 本章标题：** 看料

**2. 本章核心事件（一句话）：** 团队成员悉数登场，到缅甸克钦邦山林看料，阿龙阿虎兄弟用手电照、手掂、鼻闻等方法探料，确认是越南黄花梨上等大料（虎皮纹+鬼脸+瘿子瘤疤）。

**3. 本章在阶段中的功能：** 升级 + 小高潮
- 团队亮相，各人物性格初步展现
- 展示赌木的专业流程和技术细节
- 探到好料是第一个专业层面的爽点

**4. 主要场景（2-3个）：**
- 前往克钦邦的山路（团队成员亮相、互动）
- 缅甸林场主的料场（看料、探料过程）
- 料场仓库（确认大料品质、小高潮）

**5. 出场人物：**
- 林青峰（主角）
- 陈德彪（把头、老板）
- 阿龙（开料大师兄，性格沉稳，技术一流）
- 阿虎（开料二师兄，性格冲动，胆子大）
- 一颗痣/红姐（后勤/料场管家，性格泼辣、精明）
- 缅甸林场主貌廷（上游供应商，老狐狸）

**6. 本章释放的关键信息：**
- 团队成员：红姐（后勤，骚，目标睡够100个男人，料场大管家）、阿龙阿虎兄弟（开料师傅，老大沉稳老二冲动，技术过硬）
- 辨木口诀："一看纹二掂重三闻味四敲声，心材边材要分清，沉水不沉水是硬标准"
- 看料技术：强光手电照看纹理、紫光手电辨结构、掂重量估算密度、闻气味判断树种、敲声音听实心空心
- 专业知识：心材（格）是值钱部分、边材（白皮）不值钱、海南黄梨心材约占1/3、越南黄梨心材比例稍高
- 主角好运：随手一指的料，开窗后纹路惊艳，被说"福星""小神眼"
- 时代背景：越南黄花梨价格疯涨，一天一价，好料一出来就被抢

**7. 结尾钩子：**
行动启动型——开始正式谈价赌料，主角帮眼工作开始，陈德彪让主角也说说看法。

**8. 本章对主角成长的作用：**
- 第一次亲眼见证赌木的专业操作，建立行业认知
- 被陈德彪和阿龙阿虎认可（有灵气、福星），获得初步归属感
- 从"听说是这样"变成"亲眼见到"，入行感增强

### 第6章 变故
**1. 本章标题：** 变故

## 四、风格对齐说明

### 1. 结构层面
**完全对齐对标书的阶段结构：**

- **先抑后扬的开局结构**：先用2-3章把主角压到谷底（被骗、被羞辱、身无分文、想自杀），然后绝地反弹。对标书第1-3章的"离家→卖货→翻身（钱被偷）"结构完全照搬。
- **一章一反转的密度**：关键章节（第3、6、7章）都在一章之内完成反转甚至多重反转，节奏密度极高。第3章"大赚→钱被偷"，第6章"好料→灌铅"，第7章"废→好料反向套路"，完全对标原书的反转节奏。
- **主线+支线的张弛节奏**：赌木主线紧张刺激之后，用女主支线（第9-10章）放缓节奏，调节读者情绪，张弛有度。对标书第5-7章高潮后接第8-10章过渡的节奏模型。
- **"过来人讲过去事"的叙事框架**：开头先展示主角"后来混得不错但也付出代价"的状态，再从头讲起，给读者真实感和信心。对标书开头"出狱后在大理开超市"的框架。

### 4. 手法层面
**叙事手法完全对齐对标书：**

- **行话融入法**：先出现红木行业术语（全赌/半赌/开窗/心材/边材/满彻/捂盘/帮眼等），立刻用大白话解释，让读者和主角同步学习，既有专业感又不劝退。
- **短段落+短句**：1-3句话一段，甚至一句话一段，阅读压力小，节奏快。对标书的段落风格。
- **结尾钩子**：每章结尾都留一个悬念/问题/反转，勾着读者看下一章。钩子类型也对标：处境悬念型、希望曙光型、人物出场悬念型、行动预告型、行动启动型、悬念型、伏笔悬念型、宿命感悬念型、主线回归型。
- **情绪过山车**：大喜之后必有大悲，大悲之后必有大喜，让读者的情绪持续波动。第3章"赚三万八→钱被偷"，第7章"以为被骗→赌涨五倍"，完全对标。
- **细节真实感**：具体的价格（八百块摊位费、五万块欠款、三万八第一桶金）、具体的地名（华丰市场、姐告口岸、瑞丽江大桥、克钦邦）、具体的食物（饵丝、米线、过手米线），让故事有质感、有烟火气。
- **第一人称回忆式叙事**：以"我"的口吻叙述，代入感极强，有"过来人讲故事"的框架。
- **口语化讲述**：像说书人/老前辈讲自己的故事，有互动感强的表达，有江湖气、有阅历感。
