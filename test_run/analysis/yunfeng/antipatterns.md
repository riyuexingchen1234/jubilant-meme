## B. 烂俗桥段禁用清单

1. **主角龙傲天式碾压**：云峰是个普通人，会怕、会怂、会被骗、会受伤，不是一拳打十个的武林高手，也不是算无遗策的诸葛亮。他靠的是小聪明、讲义气、运气，不是硬实力碾压。

2. **一见钟情/后宫**：没有一见钟情，没有三妻四妾。感情线是慢慢发展的，小萱的主动也是经历过生死之后的事，不是见第一面就爱上。女性角色各有性格，不是围着主角转的花瓶。

3. **主角光环死里逃生太刻意**：死人是真死，顺子说死就死，没有"关键时刻有人来救"的刻意安排。能活下来是因为机缘巧合或者提前有准备，不是作者强行开光环。

4. **大段说教/人生感悟**：作者绝对不写"那一刻我明白了什么是江湖""经此一役我成长了"这种话。感悟都是通过行动体现，不说出来。

5. **配角降智衬托主角**：把头、鱼哥、李非都是聪明人，甚至兴爷、田三久这些反派也有脑子，没有为了衬托主角而故意写蠢的配角。主角经常是被算计的那个。

6. **反派死于话多**：兴爷、李非都是直接动手，不逼逼。兴爷插刀前还在聊天，但不是为了说"你知道你死在哪吗"这种废话，是真的在倾诉情绪。

7. **获得武功/秘籍/超能力**：从头到尾都是普通人，没有内力、没有轻功、没有祖传秘籍、没有特异功能。打架靠板砖、靠刀、靠偷袭，不是降龙十八掌。

8. **宝物发光/异象**：真古董就是旧瓶子旧碗，不会"霞光万道""瑞彩千条"，不会"一看就不是凡品"。云峰判断东西靠的是眼力，不是异象。

9. **警察/官方弱智**：警察是真的会查案，真的会抓人，主角团是真的在躲，不是把警察当摆设。

10. **兄弟反目/女人背叛**：目前样本里兄弟都是过命的交情，没有为了钱反目。小萱、豆芽仔、鱼哥、把头都是值得信任的，不是塑料兄弟情。

11. **装逼踩人**：没有"你知道我是谁吗""得罪我你死定了"这种霸总桥段。真有仇当场就报了，或者记在心里以后算，不嘴炮。

12. **拍卖会装逼**：潘家园卖货都是实打实地谈价，没有"一个亿！""两个亿！"这种拍卖会喊价装逼。

13. **古墓里大粽子/僵尸**：目前样本里都是人祸，没有真的鬼（虽然有氛围营造），危险来自于人，不是粽子血尸。

## C. 写作反模式清单

1. **绝对不要用"XX地说/道"这种副词修饰对话标签**
   - 统计佐证："冷冷地说""淡淡地说""缓缓地说"等全是0次
   - 正确做法：用动作代替情绪，"他一拍桌子""他松开刀把""他踹倒椅子"，然后直接"说"或"道"。读者自己能体会情绪。

2. **绝对不要大段心理描写和内心独白**
   - 统计佐证：心理描写仅占1.26%，且都是极短的吐槽
   - 正确做法：心理活动最多两三句，口语化，像心里骂脏话那种感觉。不要"我心中五味杂陈，既有愤怒又有悲伤，还有一丝迷茫…"这种分析式心理。

3. **绝对不要堆砌成语和华丽辞藻**
   - 统计佐证：抽样220个常见成语仅出现523次（每百万字195次），"璀璨""绚烂""瑰丽"等华丽词几乎为0
   - 正确做法：用大白话，用口语。写冷就是"冬天冷的能冻死人"，写疼就是"疼的我都喘不上气了"，写怕就是"我脸色刷的白了""我真被吓着了"。

4. **绝对不要全知视角，绝对不要上帝旁白**
   - 正确做法：全程紧跟"我"的所见所闻，"我"不知道的绝对不写。不要切换到反派视角写"此时，王兴贵正在磨刀…"，读者和主角信息永远对称。

5. **绝对不要铺垫太长，开篇必须直接上冲突**
   - 正确做法：第一句就要抓人，"我在里面待了七年"直接抛悬念。不要"在一个月黑风高的夜晚，北风呼啸，大雪纷飞…"这种环境铺垫。

6. **绝对不要"地"字结构副词（轻轻地/慢慢地/默默地/淡淡地等）**
   - 统计佐证：所有列举的"XX地"副词全是0次
   - 正确做法：直接写动词，"他走过来"不是"他缓缓地走过来"，"他说"不是"他淡淡地说"。如果需要体现慢，用短句分开写动作。

7. **绝对不要比喻堆砌，不要"宛如/犹如/仿佛"连用**
   - 正确做法："仿佛""似乎"可以偶尔用，但都是口语化的猜测（"我仿佛听到了什么""似乎有点不对劲"），不是"她的眼睛宛如星辰，嘴角犹如弯月，皮肤仿佛凝脂"这种排比比喻。

8. **绝对不要书面化的情绪描写，用动作和生理反应代替**
   - 不要写："一股寒意从尾椎骨直冲天灵盖""我心中涌起一股难以言喻的悲伤"
   - 要写："我脸色刷的白了""我后背冒冷汗""我手在抖""我咧着嘴大喘气"

9. **绝对不要章节间回顾过渡**
   - 正确做法：上一章断在哪，下一章直接接，用时间词硬切（"三天后""早上八点"），不要"上回说到…""前情提要…"。

10. **绝对不要写主角伟光正，不要正义感爆棚**
    - 正确做法：主角会怂、会跑、会贪财、会骂脏话，但有底线（讲义气、不食言、不害无辜）。不要写"我正义感油然而生""我一定要为民除害"。

11. **绝对不要把环境描写当装饰，环境必须有用**
    - 正确做法：写马灯是为了后面认身份，写烧鸡白酒是为了后面下药，写东西都是为了触发剧情或伏笔，不是为了渲染气氛而渲染。

12. **绝对不要慢动作打斗，不要武术指导式描写**
    - 正确做法：打架就是快，一句一个动作，"砰！""噗通…"人就倒了。不要"他缓缓举起拳头，眼神锐利如鹰，拳风呼啸而来…"。

13. **绝对不要排比句，少用分号和顿号**
    - 统计佐证：267万字分号仅13个，顿号仅337个
    - 正确做法：用短句，用句号，用感叹号。一个意思一句，不要用排比凑气势。

14. **绝对不要刻意搞笑，不要讲段子**
    - 正确做法：幽默来自自嘲和处境反差，比如"我觉得自己是个傻帽""别他妈聊电动车了，再不走直接买灵车吧"。不是讲网络笑话。

15. **绝对不要爽完就完了，爽点之后必须立刻给新打击**
    - 正确做法：挣了四千七→钱被偷，找到塔刹→被绑架绑架，把头出现→立刻计划去千岛湖。不让读者爽太久，刚给希望就打碎。

### D2. 对话标签正确写法（推荐）

**最推荐：动作 + 说/道**
```
兴爷松开刀把。"小子，我说了，让你安静点。"
老头一脚踹倒桌子，大声道："我就是个狗屁厂长！"
他弹了弹烟灰："我现在把你嘴松开，你别叫啊。"
```

**其次：直接 "XXX说/道/问"**
```
我说："兴爷！"
鱼哥说："拨号吧，田三久。"
他问："怎么了云峰？"
```

**再次：情绪+道（少量使用）**
```
他大声道："……"
我喊道："……"
他骂道："……"
```

### D4. 对话写法核心原则

1. **对话极度口语化**：像真人说话，允许粗口、方言、语气词、打断、说半截话。
2. **不同人说不同话**：鱼哥话少直接，豆芽仔胆小逗比，把头沉稳点拨，兴爷时而普通时而狠辣。通过用词就能分辨是谁在说话。
3. **用动作代替情绪说明**：不要"他愤怒地说"，要"他一脚踹倒桌子"；不要"他冷冷地说"，要"他把烟吐到我脸上"。
4. **对话不承担说教功能**：不说大道理，不灌鸡汤，对话就是推进剧情、塑造人物、传递信息。
5. **可以话里有话**：鱼哥打电话那段，表面是招供，实际是拖时间，读者细品能品出来，但作者不点明。
