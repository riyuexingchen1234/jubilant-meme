# 写作风格蒸馏报告

## 蒸馏对象
- 作品：《北派盗墓笔记》
- 作者：云峰
- 分析范围：第1-4卷

## 素材规模
- 总字符数：约265万字（清洁文本2,653,193字）
- 总章节数：1043章
- 样本章节：9章（开篇3章+中段3章+结尾3章）深度文学分析
- 总句数：110,949句
- 总段落数：84,233段

## 蒸馏方法
1. **全文量化统计**：对265万字全文进行分词、标点、句式、段落、对话标签、词频等多维度量化统计。
2. **9个样本章节深度文学分析**：选取开篇、中段、结尾各3章进行逐章逐段手法拆解，总结叙事规律。
3. **AI词频检测**：对AI高频词、网文烂俗词、成语使用等进行专项检测，生成反模式清单。

## 关键发现摘要

1. **极度口语化粗粝文风**：文字像"说出来的"不是"写出来的"，大量使用北方口语、粗口、江湖黑话，粗口出现频率高（"他妈"879次、"草"777次）但自然不刻意，是人物情绪真实流露。

2. **第一人称限知视角贯彻到底**：全程第一人称"我"（项云峰），读者信息永远不超过主角，偶尔插入成年后自嘲吐槽增加真实感，绝不切换视角、绝不用上帝旁白。

3. **对话驱动叙事**：对话占比高达52.11%，动作38.2%，环境8.44%，心理仅1.26%，主要靠对话推进剧情、塑造人物、传递信息，不同人物说话方式区分度极高（鱼哥话少冷硬、豆芽仔逗比嘴碎、把头沉稳有分量）。

4. **极短段落+短句节奏**：83.76%段落小于50字，一句一段，紧张时甚至一个拟声词单独成段；短句30%/中句36%/长句34%，平均句长22.42字；感叹号极多（26409个），分号几乎不用（仅13个），手机阅读体验极佳。

5. **"紧张-放松-突然暴击"的核心节奏**：危险永远在最日常的场景里突然降临，爽完就打，刚给希望就打碎，情绪曲线波浪式推进，绝不让读者安逸超过一章；章末必在最紧张处硬截断留钩子。

6. **反套路真实人物塑造**：主角是有贪念会犯怂但有底线的普通人，不是圣父不是龙傲天，会跑路会怕死；配角智商在线，反派笑里藏刀有自己逻辑，配角真会死（顺子说死就死），没有主角光环强行救人。

7. **极简白描手法**：几乎不用"XX地"副词（统计全为0），几乎不用成语和华丽辞藻，情绪通过动作和生理反应传递（脸色发白、手抖、后背冒冷汗），环境描写只写关键有用细节，不铺陈不渲染。

8. **闲笔伏笔+挤牙膏式信息释放**：伏笔像随口一提的闲笔，几十章后回收才恍然大悟；信息一点点挤给读者，绝不一次性掀底牌，读者和主角一起在黑暗中摸索。

## 注意事项
- 本规则基于云峰《北派盗墓笔记》第1-4卷（1043章）蒸馏生成。
- 作者后续作品（如第5卷及以后）风格可能有所发展变化，建议根据新文本迭代更新规则。
- 规则优先级：Layer 0（红线）> Layer 1（元规则）> Layer 2（文笔）> Layer 3（人物）> Layer 4（结构）> Layer 5（反模式）。
- 所有规则未覆盖的地方，遵循核心原则：用最口语、最朴素、最像真人说的话写。
