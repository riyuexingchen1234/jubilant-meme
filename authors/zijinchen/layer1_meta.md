# Layer 1: 元规则
- 作品总字数：约23万字
- 采样章节数：13章（开篇第1-3章 + 中段弧1第27-30章 + 高潮第46-48章 + 结尾第54-56章）
- 采样总字数：约5.6万字

## 1. 叙事视角

**第三人称限知多视角切换。**

- 不是单一主角视角，而是在多个主要人物之间切换：张一昂、方超/刘直、周荣、杜聪等，每人都有自己的视角段落
- 视角切换的标志：章节内用空行分隔，直接跳到另一个人物的场景，没有过渡句
- 每个视角段落内，读者只知道该人物知道的信息，可以进入该人物的内心想法
- 但进入内心的深度很浅，主要是"他想"、"他寻思"、"他觉得"这类直白的想法，没有深层心理剖析
- 不会进入次要人物（如营业员、路人、小弟）的内心

原文证据：第46章前半段从周荣视角写他决定动手，后半段从张一昂视角写他收到线报，中间用空行切换，没有任何过渡。

## 2. 叙事节奏

- 平均每章约4100字，每章至少推进2-3条线的剧情
- **钩子密度极高**：几乎每章末尾都有钩子，要么是新事件发生，要么是人物做出关键决定
- 快慢节奏交替模式：快节奏的动作/冲突章节后，跟着1章稍慢的布局/过渡章节，但即使是过渡章也有新信息抛出
- 没有真正意义上的"日常章"或"水章"，每章都必须推进剧情或抛出新线索
- 爽点/小高潮频率：约每2-3章一个小爽点（如张一昂歪打正着破了个案、方超又搞砸了一件事）

原文证据：第27章末尾张一昂决定"借杨威骗梅东回国"，第28章末尾杨威被吓尿同意配合，第29章末尾李茜要去赴约，连续三章章末都有钩子。

## 3. 叙事距离

- **中距离偏近**：离人物不远不近，既能看到人物动作和对话，也能听到内心想法
- 但内心描写很克制，不是大段心理独白，而是一两句话的简短想法
- **读者和主角信息不对等**：因为是多视角切换，读者往往比张一昂知道得多（比如读者知道方超是什么人、周荣在干什么，但张一昂不知道）
- 这种信息差是制造喜剧效果和悬念的重要手段——读者看着张一昂瞎猜但又歪打正着，觉得好笑

原文证据：第1章读者先看到方超和刘直策划抢劫，第2章切到张一昂这边，读者知道抢劫犯是谁，但张一昂完全不知道，形成信息差。

## 4. 时间处理

- **线性时间为主**，基本按时间顺序推进，偶尔用"一个半月前"这类倒叙交代背景（如第2章开头）
- 时间流逝写法非常直白，直接写"第二天"、"几天后"、"两天后"，没有模糊的时间过渡
- 同一天内不同视角的切换，靠"与此同时"、"另一边"这类词标示
- **几乎没有回忆/闪回**，人物不会在行动中突然陷入长篇回忆。需要交代背景时，用独立段落直接叙述，不是人物回忆
- 没有插叙、倒叙的复杂结构

原文证据：第2章开头"一个半月前"是全书少有的倒叙，但也是独立成段交代背景，不是人物闪回。

## 5. 信息控制

- **伏笔给得非常隐蔽**，很多伏笔看起来就是随口一提的细节，隔了几十章后回收时读者才意识到是伏笔
- 伏笔手法：把重要线索混在喜剧桥段里，读者被笑点吸引就忽略了线索
- **读者比主角知道得多**：多视角切换让读者掌握多条线的信息，但张一昂只知道自己这条线的。他的推理经常错，但因为其他线的意外因素，结果又对了
- 不会提前剧透：虽然视角多，但每条线的下一步发展仍然有悬念，因为线和线什么时候碰撞、怎么碰撞，读者猜不到
- 章末信息释放：每章结尾通常会抛出一个新信息或新意外，让读者想继续看下一章

原文证据：第25章杜聪只是4S店销售，看起来是个路人，但读者不知道他会成为全书高潮的关键交汇点——这就是"把重要人物混在小角色里"的伏笔手法。
