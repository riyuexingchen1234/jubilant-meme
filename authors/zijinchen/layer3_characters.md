# Layer 3: 人物塑造规则
分析样本：第1、2、3章（开头）；第27、28、29章（中间）；第54、55、56章（结尾）

## 1. 主角模板

**张一昂：**
- 出身背景：省公安厅出身，高栋的徒弟，空降三江口任刑侦副局长。
- 核心性格（固定不变）：油滑世故、运气极好、死要面子、擅长审讯话术、关键时刻靠直觉歪打正着。
- 说话方式：喜欢讲大道理装神探、审讯时话术一套接一套、对上级恭敬对下级摆架子、被拆穿时强行圆场。
- 金手指：运气（调查方向全错也能破案）、审讯心理战能力。
- 核心欲望：破大案立威信、不被高栋看扁、在三江口站稳脚跟。
- 初始困境：空降地方被排挤、刑大队长叶剑请假、手下没人可用、还得看着关系户李茜。

  原文引例：第2章高栋评价"张一昂这小子能有啥能力，办案基本靠猜！"

## 2. 配角塑造

- 配角多为功能性，但每个人都有自己的小算盘和性格特点，不是工具人。
  原文引例：第29章王瑞军为人油滑但想破大案，宋星刻板但业务能力强，各有各的追求。

- 配角出场方式：直接通过事件带出，不用单独的出场描写，在事件中展现性格。
  原文引例：第3章陈法医第一次出场是被张一昂误认为可疑人员，用事件带出人物。

- 记忆点制造：给配角一个固定标签或口头禅，如陈法医脾气硬、王瑞军拍马屁、宋星轴。
  原文引例：第55章陈法医听说有人质疑他专业，直接操起解剖刀冲出去。

- 配角内心戏极少，主要通过行动和对话展现性格。
  原文引例：第29章王瑞军听张一昂讲故事"回味咀嚼了好一阵"，用动作表现思考。

## 3. 反派塑造

- 反派不是脸谱化的坏人，各有各的蠢和可爱之处。
  原文引例：第1章劫匪方超有勇有谋讲逻辑，但队友刘直是个猪队友。

- 反派动机合理：方超刘直为了发财、周荣为了钱和权、郎博图为了保护哥哥。
  原文引例：第56章郎博图"我杀人是为了保护我哥"，动机有共情点。

- 反派出场方式：有的开篇就出场（方超刘直），有的通过背景介绍带出（周荣），有的慢慢揭露（郎博图）。
  原文引例：第1章开篇就以劫匪视角切入，直接展示反派行动。

- 主角反派互动模式：多线并行，前期主角和反派甚至不知道对方存在，后期才正面交锋。
  原文引例：第27章警方发现林凯尸体，才知道劫匪在三江口，但劫匪还不知道被警方盯上。

## 4. 对话区分度

**方超（劫匪头头）：** 沉稳、讲逻辑、喜欢讲道理、爱教育刘直、语气老气横秋。
  原文引例：第1章"稳住，暴力解决不了问题。""记住一句话，命是自己的，钱是老板的！"

**刘直（劫匪小弟）：** 憨直、愚蠢、没耐心、动不动就想动手、说话不过脑子。
  原文引例：第1章"听见没有，快把钥匙交出来！老子数到三，不交就杀人了！""早开枪不就结了。"

**张一昂（副局长）：** 油滑、装腔作势、喜欢讲大道理、审讯时话术多、被拆穿时强行圆。
  原文引例：第3章"果然不出所料！""也不能说事先知道吧，大概是多年干刑警的职业本能。"

**杨威（高利贷混混）：** 色厉内荏、表面横实际怂、讲点江湖义气、贪生怕死。
  原文引例：第28章"警察老师，现在执法都……都是很规范的，不能这样的。"

**陈法医：** 脾气硬、自尊心强、专业自负、一点就炸。
  原文引例：第55章"是你说法医不专业？""因为我的尸检报告，从来不会出错！"

- 区分度极高，不看名字也能从语气和内容判断是谁在说话。

## 5. 人物行为模式

**张一昂行为模式：**
1. 遇到事先装神探摆架子
2. 心里没底但表面镇定
3. 靠直觉/运气蒙对方向
4. 被拆穿就强行圆场
5. 审讯时用心理战和话术

- OOC红线：
  1. 张一昂绝对不会真的靠逻辑推理破案
  2. 张一昂绝对不会放下身段承认自己错了
  3. 张一昂绝对不会在下属面前露怯
  4. 张一昂绝对不会主动担责，会把功劳揽自己身上
  5. 张一昂绝对不会对李茜真的严厉，表面凶实际怕

  原文引例：第56章张一昂发现自己理解错了叶剑的暗示，马上编了个"大智若愚"的说法圆过去。

## 6. 人物变化的边界

- 核心性格不会变：张一昂的油滑和运气、刘直的蠢、方超的稳，从始至终不变。
- 会变的是处境和地位：张一昂从被排挤到逐渐立威，但性格没变。
- 人物变化通过行动选择体现，不靠内心独白，作者也不会直接点明"他变了"。
  原文引例：第29章张一昂从单枪匹马到有了王瑞军和宋星两个帮手，处境变了，但性格还是那样。

- 样本不足，无法确定人物是否有根本性转变（从全书结构看，张一昂应该有成长，但9章样本中不明显）。
