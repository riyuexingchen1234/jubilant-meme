# Layer 3: 人物塑造规则
- 作品总字数：约23万字
- 采样章节数：13章（开篇第1-3章 + 中段弧1第27-30章 + 高潮第46-48章 + 结尾第54-56章）
- 采样总字数：约5.6万字

## 一、主角塑造方法

#### 模型1：反差型主角——外强中干的幸运儿
- **核心**：主角表面上是领导、是神探，所有人都觉得他深不可测；实际上他能力平庸、经常猜错、全靠运气，但他极擅长装、极要面子，阴差阳错把所有功劳都揽到自己身上。
- **怎么用**：
  - 出身初始状态：省厅空降的副局长，高栋的徒弟，有靠山但自身能力一般
  - 核心性格（不变）：
    1. 好面子、爱装逼、永远不承认自己错了
    2. 欺软怕硬，对上级恭敬，对下级耍威风
    3. 政治敏感度高，擅长搞人际关系
    4. 骨子里有点怂，但被逼到墙角也能硬起来
  - 核心欲望：在三江口站稳脚跟、破大案立威信、别让李茜出事保住狗头
  - 固定行为反应模式：
    1. 遇到意外先愣一下，然后立刻找台阶下，装出"一切尽在掌握"的样子
    2. 推理全靠猜，猜错了就转移话题
    3. 对功劳来者不拒，甚至主动往自己身上揽
    4. 遇到危险第一反应是躲，但躲不掉时也能顶上
- **原文证据**：第2章王瑞军跑来报叶剑死讯，张一昂前一秒还在说"可千万别病死过去"，听到死讯后立刻说"果然不出所料"，把"病死"偷换成"死"，在李茜面前保住了神探形象。
- **局限性**：这种主角在严肃正剧里不适用，只能走喜剧/讽刺路线。

## 二、配角塑造方法

#### 模型2：标签化功能配角——一人一个梗
- **核心**：每个配角有且只有一个核心标签（性格特征或功能定位），出场就把这个标签打透，读者记住这个标签就能记住这个人。但标签之下又有一点出人意料的反差点，让人物不那么单薄。
- **怎么用**：
  - 出场方式：通过主角视角或对话引出，出场第一段就把核心标签交代清楚
  - 记忆点：一人一个标志性特征，反复强化
    - 王瑞军：马屁精、见风使舵，但业务能力不差
    - 宋星：老刑警、业务骨干，但情商低、经常犯傻
    - 陈法医：脾气硬、专业强，但腰椎间盘突出
    - 李茜：关系户、冲动、不怕死，但正义感强
  - 配角不是工具人，他们有自己的行为逻辑和小算盘，但他们的小算盘最终会服务于主线剧情
  - 配角的"反差点"：每个标签化配角都有一个意外面——王瑞军马屁精但关键时候靠得住、宋星刻板但正义感极强
- **原文证据**：第3章陈法医出场，先通过张一昂的视角以为他是嫌疑人，然后王瑞军解释"他是主法医老陈"，接着马上补"腰椎间盘突出"的特征，一句话立住人物。
- **局限性**：配角深度有限，不适合写复杂的人物弧光，但在群像喜剧里足够用。

## 三、反派塑造方法

#### 模型3：降维反派——有能力但架不住猪队友
- **核心**：反派本身能力不差、智商在线、做事谨慎，但架不住身边人全是猪队友，或者运气太差，最后不是被主角打败的，是被自己人和意外搞垮的。
- **怎么用**：
  - 周荣（大BOSS）：有钱有势、谨慎心细、有决断力，但手下张德兵、胡建仁能力一般，最后栽在杜聪这个路人手里
  - 方超（劫匪线反派）：有计谋、有胆量、做事有条理，但搭档刘直是个蠢货，每次都坏他的事
  - 郎博图（终卷反派）：心思缜密、杀人计划设计得很巧妙，但最后还是被张一昂瞎猫碰死耗子逮住了
  - 反派不是脸谱化的坏人，他们有自己的行事逻辑和为人准则（比如方超有"职业道德"、周荣对兄弟讲义气）
  - 反派和主角的互动：不是正面斗智斗勇，而是多线并行、意外碰撞，主角甚至不知道反派在干什么
- **原文证据**：第32章方超抢周荣，计划很周密——踩点、伪装、调虎离山、控制场面。但刘直劈人劈了好几下才劈昏，最后出门还遇到杜聪车祸，一连串意外导致计划走样。
- **局限性**：这种反派塑造适合喜剧和讽刺，不适合写正剧里那种势均力敌的智斗。

## 四、对话区分度方法

#### 模型4：身份+性格双维度区分
- **核心**：不同人物的对话通过"社会身份"和"性格标签"两个维度区分，一听就知道是谁在说话，不需要看人名。
- **怎么用**：
  - **张一昂**：官话套话+耍无赖混合体。平时对下属说官话（"办案不是儿戏，要站在全局角度"），急了就耍无赖（"他不清楚，那就没问题了"），还有大量装逼台词
  - **方超**：像老师/老板说话，爱讲道理、爱总结、爱用比喻，经常说"你想想""道理很简单""记住一句话"
  - **刘直**：话少、直接、蠢，经常问弱智问题，开口就是"为啥""那怎么办""我——"
  - **周荣**：沉稳、简洁、有威严，说话像老板下命令，"直接动手""一样灭口"，话不多但每句都有分量
  - **小人物（刚哥、小毛、杜聪）**：最口语化，像真实生活里的普通人说话，有口头禅、有废话、会结巴
- **原文证据**：同样是遇到意外情况——
  - 张一昂："果然不出所料！"（先装逼）
  - 方超："好手段，好手段！"（先总结评价）
  - 刘直："我非杀了他们不可！"（直接喊）
  - 周荣："既然歹徒也不信任这笔交易了，那就一不做二不休，直接动手！"（冷静下命令）
- **局限性**：人物特别多的时候容易出现标签重复，需要靠不同的功能定位来区分。

## 五、人物行为OOC红线

1. **张一昂绝对不会主动承认自己错了。** 哪怕铁证如山，他也会找各种借口搪塞过去，或者转移话题，或者用气势压人。
   原文证据：第3章他把法医当嫌疑人，被拆穿后立刻转怒"那还不赶紧把尸体拖回去"，用发脾气掩盖尴尬，绝不承认自己看错了。

2. **刘直绝对不会突然变聪明。** 他可以偶尔运气好蒙对一次，但绝大多数时候都是蠢的，而且蠢的方式一致——不动脑子、冲动、想当然。
   原文证据：第1章抢金店搬财神像，第26章建议直接埋人，从头到尾都是同一智商水平。

3. **周荣绝对不会亲自动手打人杀人。** 他是老板，永远坐在幕后指挥，让小弟去动手，他只做决策。哪怕最后亲自去现场，也是指挥，不是亲自动手。
   原文证据：第47章他决定上楼抓人，但说的是"让张德兵召集几个最靠得住的小弟，上楼抓人"，自己是跟着去但不是动手的。

4. **方超绝对不会杀无辜的人。** 他是劫匪不是杀人犯，有自己的底线——抢劫但不杀人，甚至还讲道理。哪怕被激怒了嚷嚷着要杀人，最后也不会真动手。
   原文证据：第26章方超纠结要不要杀路虎车主，"他们从没杀过人，万一将来某天被抓了，以前犯下的事只是抢劫罪，判不了死刑，可手上一旦沾了人命就不一样了"。

5. **李茜绝对不会因为危险就退缩。** 她胆子极大，越是危险越往前冲，天不怕地不怕，因为她有靠山也因为性格如此。
   原文证据：第3章第一次去命案现场，其他新人可能会吓傻，她反而"眼睛里透出磨刀霍霍的光亮"。
