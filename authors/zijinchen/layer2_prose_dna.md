# Layer 2: 文笔DNA
- 作品总字数：约23万字
- 采样章节数：13章（开篇第1-3章 + 中段弧1第27-30章 + 高潮第46-48章 + 结尾第54-56章）
- 采样总字数：约5.6万字

文本统计数据：平均句长30.6字，长句占50.5%，短句占20.1%；对话占比38.9%；平均段落长52.9字，短段落（<50字）占62.1%。

## 一、句式偏好

#### 模型1：短长交替推进句
- **核心**：用1-2个短句起头抛信息，再接1个长句补细节，节奏感像"蹦—蹦—滑"，短的打节拍，长的铺内容。
- **怎么用**：
  - 场景开头用短句定调："夜已至。""第二天中午。""与此同时。"
  - 动作描写用短句："方超掏出枪。""刘直愣了一下。"
  - 背景交代、心理活动、复杂情况用长句，但长句内部也是逗号断开的流水句，不是复杂从句
  - 紧张场景短句密度提高，搞笑场景长短交替更明显（先短句铺垫，再长句抖包袱）
- **原文证据**：第1章抢劫金店："两人套上胶皮手套，大步走向黄金店。快到店门口的监控区域前，他们快速抽出一张塑料面具戴在脸上，刘直拿出两张印有'停业装修'的贴纸，往店面玻璃门上左右一拍。两人闪身进店，关上门，方超掏手枪，刘直拿出一把长匕首，双双扑到店里三个猝不及防的女营业员面前。"——短+长+短交替。
- **局限性**：在需要大段抒情或深度心理描写时不适用，但作者几乎不写这类场景。

## 二、段落节奏

#### 模型2：对话主导的碎片段落
- **核心**：段落极短，大量单句成段、单句对话成段，像剧本一样推进，读起来速度快、不费眼。
- **怎么用**：
  - 对话基本一句一段，引导词（"某某说"）有时在前有时在后，但绝不把两个人的话放在同一段
  - 叙述段落也很短，一般1-3句话一段，超过5句话的段落极少
  - 动作描写和对话穿插，动作单独成段，对话单独成段，交替推进
  - 搞笑时尤其喜欢单句成段，包袱单独成段，放大喜剧效果
- **原文证据**：第3章张一昂发现死者写自己名字：
  ```
  "他是……"王瑞军支吾不语。
  张一昂看他表情就知道定有内情，正色道："你放八百个心，我的岗位是行政高配的，背后是公安厅，在三江口这里，不管是谁干的，我都敢毫无保留地查他，叶剑写了谁，你只管说出来！"
  "他……他写了您的名字。"
  "我——"张一昂吞下一大口空气，冷声喝道，"照片拿给我看！"
  ```
  几乎全是短段落，对话单独成段。
- **局限性**：在需要浓墨重彩描写大场面时可能显得单薄，但作者靠多线切换弥补了这一点。

## 三、对话风格

#### 模型3：身份错位式对话
- **核心**：对话的笑点主要来自"身份和说的话不匹配"——劫匪讲经济学道理、罪犯讲职业道德、警察耍流氓手段，正经人说不正经的话，不正经的人说正经的话。
- **怎么用**：
  - 方超（劫匪）说话像老师/老板："暴力解决不了问题。""经济学上有个理论，人的一生至少会遇到三次大机遇。"
  - 张一昂（警察）说话像流氓/无赖："那就不当传唤，当刑案重点嫌疑人进行调查拘留，就不用管二十四小时了。""他不清楚，那就没问题了。"
  - 小人物（杜聪、刚哥、小毛）说话最接地气，像真实生活里的普通人
  - 引导词很少用"某某道""某某淡淡地说"，多用"某某说""某某问""某某喊道"，简单直接
  - 话不直说的情况：人物不会绕弯子暗示，要么直接说，要么靠动作表情传递，对话本身很直白
- **原文证据**：第1章方超抢劫时跟营业员讲道理："我相信你们一定是第一次遇到这样的事，你们肯定很害怕，你们在考虑要不要把钥匙交出来。其实道理很简单，你们上班赚多少？有必要为了这点儿工资搭上性命吗？记住一句话，命是自己的，钱是老板的！"——劫匪给被害人做思想工作，身份错位产生喜剧效果。
- **局限性**：用多了容易变成段子集，需要靠剧情推进来平衡。

## 四、用词偏好

#### 模型4：口语化白话+精准比喻
- **核心**：整体是大白话、口语化，但偶尔一个比喻极其精准毒辣，一击即中，让人印象深刻。
- **怎么用**：
  - 95%的文字是最普通的现代汉语，没有生僻词、没有华丽辞藻
  - 比喻都是生活化的、接地气的，不用古典意象、不用文艺比喻
  - 比喻集中在人物状态和心理感受上，不用来描写景物
  - 典型比喻："便秘患者即将舒畅之际突遭痔疮破裂痛昏倒地""笑得快裂到耳垂的嘴巴""像一条矫捷的狼"
  - 绝对不用的词："宛若""犹如""宛如""恰似"这类文气的比喻词，比喻直接用"像""仿佛""就像"
- **原文证据**：第2章写叶剑对张一昂空降的心情："结果张一昂突然空降，犹如一记老拳正中叶剑心窝，便秘患者即将舒畅之际突遭痔疮破裂痛昏倒地，这心情可想而知！"——用便秘比喻升职落空，极其精准又搞笑。
- **局限性**：比喻太接地气，写严肃悲情场景时可能出戏，作者一般避开这类场景。

## 五、描写习惯

#### 模型5：功能优先的极简描写
- **核心**：所有描写都服务于剧情推进或人物塑造，没有纯装饰性描写。环境描写只交代必要信息，人物外貌只写最有辨识度的特征。
- **怎么用**：
  - 环境描写：只写和剧情相关的部分。比如写居民楼，只写"单元楼""小区保安是退伍兵"这些跟后续情节有关的，不会写楼的外观怎么样
  - 人物外貌：出场时一句话带过最核心的特征，之后再也不写。如周荣"外形俊朗、五官棱角分明，由于经常健身，没有肚子的身材"
  - 动作描写：最细致，是推进剧情和表现人物的主要手段
  - 感官切入顺序：先视觉（看到什么），再听觉（听到什么），很少写嗅觉、触觉、味觉
  - 场景建立的套路：一句话交代时间地点→直接进入人物动作和对话
- **原文证据**：第3章写案发现场："案发现场是河边的一处绿地，城市叫三江口，自然河道众多。城市里很多内河两岸都布置成了绿地公园，种着花草树木。事发这块地方树木繁茂，平时人也不多"——三句话交代完环境，马上进入剧情，没有多余描写。
- **局限性**：场景画面感不强，读者对环境的印象比较模糊，但人物和剧情印象深刻。

## 六、情绪表达

#### 模型6：动作外化情绪
- **核心**：情绪从不直接说"他很愤怒""她很伤心"，全部通过具体的动作、语言、生理反应外化。愤怒就想打人、伤心就发呆、紧张就咽口水。
- **怎么用**：
  - 愤怒："张一昂气得只想一榔头了结陷害他的人""方超激动得抓起旁边一条椅子狠狠往地上掷去，摔得四分五裂"
  - 惊讶/心虚："张一昂咽下一大口空气""张一昂咽了下唾沫"
  - 高兴/得意："张一昂喜出望外""把笑得快裂到耳垂的嘴巴收回去"
  - 紧张/纠结："周荣仰面躺在沙发上寻思了片刻，豁然坐直身体"
  - 情绪爆发前必有铺垫：先写身体反应（咽口水、攥拳头、深呼吸），再爆发出来
- **原文证据**：第3章张一昂发现被陷害，不说"他又气又惊"，而是写"张一昂气得只想一榔头了结陷害他的人"——用具体动作表达愤怒。
- **局限性**：极度细腻复杂的情绪（如爱恨交织、愧疚悔恨）不容易表达，但作者的人物大多性格直白，没有太复杂的情绪。
