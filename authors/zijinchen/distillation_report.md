# 紫金陈《低智商犯罪》风格蒸馏报告

## 一、作者最核心的5个写作心智模型

1. **多线碰撞法**：故事不是主角推进的，是3-5条独立线索意外碰撞出来的。每条线的人物都有自己的目标和行动逻辑，他们不知道其他线的存在，在某个时间地点撞在一起，碰撞产生的意外就是剧情转折点。

2. **信息差喜剧**：读者站在上帝视角知道所有线的情况，人物只知道自己这条线的。人物基于不完整信息做出的判断和行动，在读者看来特别滑稽。最大的信息差是"所有人都觉得张一昂是神探，只有读者知道他全靠运气"。

3. **反差型主角**：主角表面上是领导、是神探，所有人都觉得他深不可测；实际上他能力平庸、经常猜错、全靠运气，但他极擅长装、极要面子，阴差阳错把所有功劳都揽到自己身上。

4. **身份错位对话**：对话的笑点来自"身份和说的话不匹配"——劫匪讲经济学道理、警察耍流氓手段、黑社会老板谈职业道德。正经人说不正经的话，不正经的人说正经的话。

5. **喜剧包装严肃推进**：表面上全是段子和笑点，但底层剧情是严肃推进的——案件在查、线索在走、人物关系在变。每个喜剧桥段都同时推进至少一个剧情点，笑点和剧情绑定，不是水字数。

## 二、模仿这个作者写小说，最需要抓住什么

1. **多线叙事能力**：这是最难也是最核心的。要能同时hold住3-5条独立的线，每条线有清晰的目标和动机，线和线之间要能自然碰撞，碰撞的结果要出人意料但又在情理之中。

2. **信息差的把控**：什么时候让读者知道、什么时候让人物知道、知道多少，这个节奏要精准。信息差既是笑点来源也是悬念来源，不能一直吊着读者，要适时揭露一部分。

3. **喜剧和剧情的绑定**：不能为了搞笑而搞笑，每个笑点都要同时推进剧情或塑造人物。段子是皮，故事是骨，皮要长在骨头上，不能皮是皮肉是肉。

4. **人物的一致性**：特别是蠢人要一直蠢、装逼的人要一直装逼，不能为了剧情需要突然变聪明或突然变怂。人物的行为必须符合已经建立的人设，出岔子也要从人设里出。

5. **快节奏**：每章都要有推进，不能有水章。章末必有钩子，视角切换要卡在节点上，让读者一直想往下看。

## 三、模仿这个作者写小说，最需要注意补位什么缺陷

1. **人物深度不足**：多线叙事+快节奏容易导致人物内在变化写得少。长篇写作中要有意识地给主要人物安排"静下来"的时刻，让读者看到他们的内心和变化，不然人物容易变成推动剧情的工具。

2. **情感冲击力不够**：全程喜剧基调会削弱严肃场景的情感重量。在重要人物死亡、重大背叛、结局收束等场景，要主动收一收笑点，让节奏沉下来，给读者动情的空间。

3. **"靠运气破案"的模式容易重复**：张一昂每次都歪打正着，用多了读者会腻。要有变化——有的案子靠运气、有的靠手下、有的靠蒙对方向、有的靠反派自己露馅。连续3个案子不能是同一种"破"法。

4. **配角容易标签化**：一人一个梗的写法很高效，但梗用完了人物就没东西了。要给每个主要配角加一个"意外面"——和标签相反的特质，而且不要太早暴露，隔一段时间露一点，保持新鲜感。

## 四、采样中发现的矛盾/不一致之处

1. **张一昂的能力水平前后略有不一致**：有时候他显得特别蠢（把法医当嫌疑人、推理全错），有时候又能想出"借杨威骗梅东""围会所打市长"这类看起来挺高明的计策。可能作者需要他蠢的时候就蠢，需要他推进剧情的时候就突然有点小聪明。

2. **方超的"不杀人"底线在后期有所动摇**：前期方超明确说不杀人，抢路虎车主时也纠结要不要杀。但到了中后期（第45章），方超被刚哥小毛激怒后嚷嚷着"一定要将这两浑蛋碎尸万段"，虽然可能只是气话，但和前期的谨慎人设略有出入。

## 五、样本不足无法确定的点

1. **感情戏写法**：采样章节中没有正经的感情戏（张一昂和李茜是上下级+关系户的恐惧关系，不是感情线）。不确定作者写男女感情是什么风格。

2. **悲情场景写法**：采样中没有纯粹的悲情场景——死亡都是用喜剧口吻写的。不确定作者写真正的悲剧、真正的煽情是什么水平。

3. **大场面/群像戏写法**：采样中的"大场面"（第48章火并）也是多线切换、快速剪辑的写法，没有那种数百人混战的大场面。不确定作者写超大规模场景的能力。

4. **作者是否擅长写女性人物**：采样中女性人物很少（李茜、周淇、蒋英），且都比较功能化。不确定作者写复杂女性角色的能力。
