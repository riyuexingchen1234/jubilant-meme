# Layer 2: 文笔DNA
- 作品总字数：约267万字
- 采样章节数：35章（开篇第1-6章 + 中段弧1第18-29章 + 中段弧2第241-250章 + 结尾第507-514章）
- 采样总字数：约9.2万字

文本统计数据：平均句长23.6字，长句占37.3%，短句占27.3%；对话占比29.2%；平均段落长31.9字，短段落（<50字）占83.3%。

## 一、句式偏好

#### 模型1：聊天式流水短句
- **核心**：句子短、散、口语化，像人聊天时想到哪说到哪，一句话说一件事，下一句接下一件事，没有复杂从句和长难句。
- **怎么用**：
  - 大部分句子是简单句，主语（我/他/她）+ 谓语 + 宾语，结构极简
  - 句子之间靠意思连接，不靠关联词（因为...所以.../虽然...但是...用得极少）
  - 短句多、单字成句多："啊？""哦。""草！""妈的。"
  - 紧张场景句子更短，一个动作一句话，像机关枪一样突突突
  - 科普/回忆场景句子稍长，但也是流水句，不是复杂结构
  - 大量"我+动词"开头的句子："我看...""我想...""我说...""我掏出..."
- **原文证据**：第2章被光头摊主踹了之后：
  ```
  他狠狠的朝我肚子上踹了一脚。
  我当时才多大，哪里打的过这光头，顿时疼的都直不起腰来。
  身边人越来越少，大家都收好摊装三轮车拉走了，踹我的光头男也走了。
  寒冬腊月，北京虽然比不上漠河，但晚上也很冷。
  市场保安牵着大狗，见我收摊慢，还不停的催我，说要是晚点了会罚我款。
  ```
  每句一件事，流水一样往下走，没有任何复杂结构。
- **局限性**：在需要表达复杂逻辑或细腻情感时可能显得单薄，但作者靠真挚的感受和快节奏弥补了这一点。

## 二、段落节奏

#### 模型2：碎碎念式短段落
- **核心**：段落极短，一句话一段、两句话一段是常态，读起来像打字聊天，一行一行刷下来，视觉上非常轻松。
- **怎么用**：
  - 80%以上的段落只有1-2句话
  - 对话一句一段，动作一句一段，心理活动一句一段，交替推进
  - 重要的信息或情绪单独成段，制造强调效果
  - "回忆插叙"单独成段，用"后来我才知道""现在回头看"开头
  - 科普知识点的段落稍长（3-5句），但也控制在短段落范围内
  - 大段描写基本没有，超过5句话的段落非常少
- **原文证据**：第3章钱被偷后的反应：
  ```
  钱没了……
  我千辛万苦挣的四千多块，没了。
  "钱呢！我钱呢！"当时我吓的脸都白了，拼命的胡乱翻床单，翻枕头。
  可是什么都没有了，只剩下了干瘪的黑塑料袋。
  ```
  四句四段，每句一段，情绪层层递进。
- **局限性**：段落太碎可能导致画面连续性不够，但作者的故事性很强，读者被剧情牵着走，不会注意到段落碎。

## 三、对话风格

#### 模型3：大白话+身份感对话
- **核心**：对话全是大白话，没有一句书面语。每个人说话符合他的身份和性格——乡下人说乡下话、江湖人说江湖话、老板说老板话，一听就知道是谁在说话。
- **怎么用**：
  - **主角（云峰）**：实诚、有点怂、嘴甜（对前辈）、会算账，经常说"是""知道了""为啥""真的假的"
  - **王把头**：沉稳、有威严、话不多但句句有分量，开口就是行话或安排工作
  - **孙老二/老三**：江湖气、粗口多、直来直去，"草！""妈的""牛逼"挂嘴边
  - **一颗痣**：风骚、爱开玩笑、爱撩拨人，话里带刺但也有分寸
  - 对话引导词极简："我说""他说""XX道"，很少用"XX冷冷地说""XX微微一笑说道"
  - 对话里有大量口语词："咋""啥""呗""嘛""得了""拉倒""咋回事"
  - 吵架/紧张时对话更碎更短，一句顶一句
- **原文证据**：第5章孙老二发现夯土层：
  ```
  "草！王把头！云峰这小子是福星啊！有两年没见过这种大坑了！"
  "一铲子打到了夯土层，白膏泥连着青膏泥！"
  "要么是西周贵族！要么是小诸侯王！"
  "咱们要发了！"
  "嘘！二哥你小点声，"孙老三皱眉提醒。
  ```
  对话直接、情绪外露、有江湖气，完全符合孙老二的人设。
- **局限性**：人物多了容易出现"说话都一个味"的问题，但作者靠人物功能定位不同（把头/土工/散土/后勤）来区分。

## 四、用词偏好

#### 模型4：江湖口语+专业术语混合
- **核心**：日常叙述是大白话+粗口，但一涉及专业领域（盗墓、鉴宝、风水、行规），立刻蹦出大量行话术语，形成"外行看热闹，内行看门道"的层次感。
- **怎么用**：
  - **日常用词**：最普通的现代汉语，怎么口语怎么来，粗口是调味品
  - **行话术语**：大量盗墓行话——散土、灌顶、劵顶、新锅剩锅、眼把头、卖米郎、土工、一颗痣、飞针探土，等等
  - **鉴宝术语**：洋蓝、粉彩、青花、鸡爪纹、冲线、包浆、开门、一眼假，等等
  - **风水口诀**："关锁截横栏，分明居两边，高山平地穴，大坑葬中间""寻龙千万看缠山，一重缠是一重关"
  - 术语不是硬塞的，是在剧情推进中自然带出来的，而且每次出现都会用大白话解释一遍（或者通过上下文让读者猜出来）
  - 解释术语的方式：要么通过人物对话解释，要么用"行话的意思就是..."直接解释
- **原文证据**：第4章介绍团伙分工时，把"眼把头""卖米郎""土工""放风人""后勤办""散土"这些行话一个个用大白话解释清楚，既是科普也是剧情的一部分。
- **局限性**：术语太多可能让读者看不懂，但作者解释得很及时，而且术语本身就有神秘感，能吸引读者。

## 五、描写习惯

#### 模型5：感受优先的功能描写
- **核心**：所有描写都从"我"的感受出发，不是客观描写环境，而是写"我看到了什么、我听到了什么、我感觉到了什么、我心里怎么想"。描写只为两个目的服务：推进剧情、表达感受。
- **怎么用**：
  - **环境描写**：极简，只交代必要信息（在哪、有啥、能不能用），3句话以内解决
  - **人物外貌**：出场时1-2句话带过最突出的特征，之后再也不写
  - **动作描写**：最细致、最具体，是推进剧情的主要手段
  - **心理描写**：极多、极直白，想到什么说什么，不装
  - 感官顺序：视觉（看到什么）→ 听觉（听到什么）→ 触觉（冷/热/疼）→ 心理（害怕/激动/贪财）
  - 场景建立的套路：一句话交代地点 → "我"的动作和感受 → 直接进剧情
  - 绝对没有独立的"景物描写段"或"外貌描写段"，所有描写都揉在行动和感受里
- **原文证据**：第5章第一次下盗洞前的环境：
  ```
  顺德顺峰山公园西南边，有个小山沟，当地人叫飞蛾山，老把头说大坑就在飞蛾山的半山腰上。
  ```
  一句话交代完，马上进剧情（找位置、下铲），没有任何山景描写。
- **局限性**：场景画面感不够强，读者对环境的印象比较模糊，但人物的感受非常清晰。

## 六、情绪表达

#### 模型6：直白外放的情绪流
- **核心**：情绪从不藏着掖着，高兴就笑、生气就骂、害怕就发抖、贪财就心跳加速，全部直接写出来，不搞"含蓄表达""侧面烘托"那一套。
- **怎么用**：
  - 高兴："脸都快要笑烂了""放声大喊""心里狂喜"
  - 害怕："吓得脸都白了""浑身发抖""心脏砰砰跳"
  - 生气："气得脸色通红""咬牙切齿""爆粗口"
  - 贪财："心头狂跳""眼睛都直了""咽了口唾沫"
  - 情绪是流动的，不是一个状态定死——上一秒还害怕，下一秒看到宝贝就贪财压过了害怕
  - 情绪变化非常快，符合年轻人（主角年龄小）的心理特点
  - 情绪表达常用"最直接的生理反应"：心跳加速、脸通红、手心出汗、腿软、咽口水
- **原文证据**：第3章第一次赚大钱：
  ```
  两手空空的出了报国寺，我摸着衣服里厚厚的一叠百元大钞，脸都快要笑烂了。
  我站外广安门桥上，手持巨款，放声大喊:"皇天不负有心人，我项云峰念书不行，但我天生是块做生意的料！大姑父的农家乐算个屁！我以后要当全国最牛逼的古董商！"
  ```
  高兴就直接写"脸都快要笑烂了""放声大喊"，不搞什么"心中窃喜""嘴角上扬"。
- **局限性**：情绪太直白可能缺少余味，但配合快节奏的剧情和第一人称的代入感，反而非常有感染力。
