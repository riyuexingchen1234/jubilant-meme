# Layer 3: 人物塑造规则
- 作品总字数：约267万字
- 采样章节数：35章（开篇第1-6章 + 中段弧1第18-29章 + 中段弧2第241-250章 + 结尾第507-514章）
- 采样总字数：约9.2万字

## 一、主角塑造方法

#### 模型1：成长型小人物——怂但韧，贪但正
- **核心**：主角不是天生厉害的人，是个从底层摸爬滚打起来的普通人——有点怂、有点贪、有点笨，但有韧性、有底线、讲情义，在一次次冒险中慢慢成长。
- **怎么用**：
  - 出身初始状态：东北山村穷小子，没爹没妈，奶奶养大，小学文化，16岁离家闯社会
  - 核心性格（底层不变）：
    1. 贪财但不贪得无厌——爱钱、会算账、想发财，但有底线，不该拿的不拿
    2. 胆小但不懦弱——遇到危险会害怕、会发抖、会想跑，但真被逼到份上也能咬牙顶上去
    3. 实诚但不傻——对信任的人掏心掏肺，但被坑过几次后也学会了看人
    4. 重情义——谁对他好他记一辈子，知恩图报（为了救李静敢借五万块）
  - 成长弧光：从"为了挣钱什么都敢干"的愣头青 → 逐渐懂得行规、懂得人心、懂得敬畏 → 最后明白"这行不是长久之计"，但已经回不了头
  - 固定行为反应模式：
    1. 遇到值钱的东西：心跳加速、眼睛发直、咽口水，但表面还要装淡定
    2. 遇到危险：先慌一下，然后强迫自己冷静，想办法（想不出来就跑）
    3. 被前辈夸奖：心里美滋滋，表面还要装谦虚
    4. 遇到不平事：虽然怕，但忍不住要管（尤其是对自己好的人）
- **原文证据**：第18章为了救李静，敢找王把头借五万块——这对一个16岁的穷孩子来说是天文数字，但他为了报恩敢借。第6章王把头问他干不干，他说"把头，我要挣钱"——动机直白但真实。
- **局限性**：这种主角在爽文读者看来可能"不够爽"，但胜在真实、有代入感，读者看着他成长就像看着自己成长。

## 二、配角塑造方法

#### 模型2：功能标签+人性厚度
- **核心**：每个配角首先有一个明确的功能定位（技术担当/后勤担当/武力担当/引路人），一个标签化的特征让人记住。但标签之下有复杂的人性——不是好人也不是坏人，是各有算盘、各有底线的江湖人。
- **怎么用**：
  - 出场方式：通过主角视角观察，出场第一段就把功能定位和核心特征交代清楚
  - 记忆点：一人一个标签，反复强化
    - 王把头（引路人/眼把头）：神秘、沉稳、看事准、话少但分量重
    - 孙老二（土工/二哥）：脾气爆、技术好、直来直去、江湖气重
    - 孙老三（土工/三哥）：心细、谨慎、话不多但靠谱
    - 孙老大（放风/大哥）：表面老实、心里有数、能扛事
    - 一颗痣（后勤）：风骚、爱撩拨、但业务能力强、关键时刻靠得住
  - 配角的"厚度"：每个配角都有不为人知的一面——王把头也有软肋、孙老二虽然爆但对兄弟好、一颗痣风骚但有原则
  - 配角不是工具人，他们有自己的目的和算盘，跟主角合作是因为利益一致，不是因为"主角光环"
  - 配角会死、会走、会背叛，不是永远跟着主角的固定班底
- **原文证据**：第4章一颗痣出场，先给标签"笑起来有点骚，眼下有颗黑痣，外号一颗痣，目标是睡够一百个男人"，标签非常鲜明。但后续剧情里她不是只会骚的花瓶——后勤工作做得极好、下墓也不拖后腿、有自己的行事准则。
- **局限性**：配角太多时容易标签重复，需要靠不同的功能定位和不同的"反差点"来区分。

## 三、反派塑造方法

#### 模型3：灰色反派——没有绝对的坏人，只有立场不同的人
- **核心**：没有纯粹的"邪恶反派"，所有对手都是各为其主、各谋其利的江湖人。他们有自己的行事准则和底线，有的甚至比主角还讲道义。对手和主角的冲突是利益冲突，不是善恶冲突。
- **怎么用**：
  - 同行对手（南派盗墓贼）：技术好、路子野、跟主角抢墓，但也讲行规，不会赶尽杀绝
  - 黑吃黑的：真·坏人，不讲规矩，是真正的反派，但这种人也有自己的逻辑
  - 官方（警察/考古队）：站在主角对立面，但不是坏人，人家是干本职工作
  - 反派的"人味"：再坏的反派也有自己在乎的人、自己的原则、自己的难处
  - 主角和反派的关系：不是你死我活，经常是"这次是对手，下次可能是朋友"，江湖嘛，山水有相逢
- **原文证据**：第6章发现墓被南方人盗过了，主角一方的反应是"捡破鞋来了"——是同行竞争的气愤，不是"一定要把对方杀光"的仇恨。姚家兄妹（南派）后面还跟主角合作过，江湖人没有永远的敌人。
- **局限性**：缺少"终极反派"可能导致长线悬念不足，但作者靠单元剧结构和一个个新冒险弥补了这一点。

## 四、对话区分度方法

#### 模型4：身份+性格+地域三维度区分
- **核心**：人物对话通过"社会身份+性格特征+地域/江湖背景"三个维度区分，每个人说话的语气、用词、节奏都不一样，不看人名也能猜个八九不离十。
- **怎么用**：
  - **王把头**：话少、沉稳、不怒自威，开口要么是行话口诀要么是工作安排，从不废话。"云峰啊，关锁截横栏，分明居两边，高山平地穴，大坑葬中间。"
  - **孙老二**：嗓门大、直来直去、粗口多、情绪外露，开心就笑生气就骂，不藏着掖着。"草！王把头！云峰这小子是福星啊！"
  - **孙老三**：话不多、声音稳、考虑周全，开口就是技术细节或提醒注意。"嘘！二哥你小点声。""二哥，不能下了！下面就是墓道！"
  - **一颗痣**：语调风骚、爱开玩笑、爱撩拨，但正事上不含糊。"呦呦呦，又来新人了，这也太小了吧，就是不知道下面小不小…"
  - **主角（云峰）**：前期语气嫩、有点怂、对前辈恭敬、经常问"为啥""真的假的"，后期逐渐沉稳但底色还是实诚。
  - **共同点**：全是大白话，全是口语，没有一个人说话像写作文
- **原文证据**：同样是"发现墓被人盗了"这件事——
  - 孙老二："草！这他妈是冲击钻打下来的！""这西周墓被人摸过了！"（爆粗+直接+愤怒）
  - 王把头："那都是碰运气的，就算是个剩锅，但凡里面还有两片肉，咱们这趟都不算白来。"（沉稳+先稳军心+讲现实）
  - 主角："啊？"（懵+没反应过来+菜鸟反应）
- **局限性**：人物特别多时容易出现说话风格趋同，需要靠不同的口头禅和说话节奏来区分。

## 五、人物行为OOC红线

1. **项云峰绝对不会在没被逼到份上的时候主动逞英雄。** 他是普通人，能躲就躲、能跑就跑，只有退无可退或为了在乎的人时才会硬上。
   原文证据：第2章被光头摊主踹了一脚，他的反应是"当时我人都傻了"，不是冲上去拼命，符合普通人的反应。

2. **王把头绝对不会情绪失控、不会大喊大叫、不会慌。** 他永远是稳的，哪怕天塌下来也面不改色，这是他作为"把头"的威严和担当。
   原文证据：第6章发现墓被盗了，王把头的反应是"那都是碰运气的"，先稳军心再想办法，不是暴跳如雷。

3. **孙老二绝对不会玩阴的、不会背后捅刀子。** 他是直人，不爽就骂、要打就当面打，光明正大，阴招损招他不屑用。
   原文证据：从头到尾孙老二的情绪都是外放的，开心就笑生气就骂，没有藏着掖着的时候。

4. **一颗痣绝对不会因为感情影响工作。** 她风骚归风骚，但专业上极其靠谱，该干什么干什么，不会因为跟谁有私情就坏了规矩。
   原文证据：第5章她撩拨归撩拨，但后勤工作做得一丝不苟，装备物资准时到位，业务能力没得说。

5. **项云峰绝对不会忘了谁对他好。** 谁帮过他、谁救过他，他记一辈子，有机会一定会报恩，这是他最核心的"正"。
   原文证据：第18章为了救李静（一个只认识几天、救过他一命的女孩），敢找王把头借五万块，这对当时的他来说是天文数字。
