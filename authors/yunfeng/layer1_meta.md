# Layer 1: 元规则
- 作品总字数：约267万字
- 采样章节数：35章（开篇第1-6章 + 中段弧1第18-29章 + 中段弧2第241-250章 + 结尾第507-514章）
- 采样总字数：约9.2万字

## 1. 叙事视角

**第一人称限知视角（"我"=项云峰）。**

- 全程第一人称"我"来叙述，读者只知道"我"知道的信息，"我"不在场的事情通过对话或转述得知
- 但这是"回忆式第一人称"——叙述者是出狱后、开超市的中年项云峰，在回忆年轻时的经历
- 所以叙述中经常穿插"现在回头看""如今过去十五六年了""我后来才知道"这类"过来人"的评论和补充
- 这种双时间线（叙事的现在时 vs 故事的过去时）是重要的风格特征
- 可以进入"我"的内心，心理活动非常多且直白，想到什么就说什么
- 其他人物的内心完全不知道，只能通过他们的言行猜测
- 偶尔会用"后来我才知道""若干年后我才听说"的方式补充"我"当时不知道的信息，但这是回忆者视角的补充，不是上帝视角

原文证据：第1章开头"我在里面待了七年"就是回忆视角，第3章"如今过去十五六年了，每当想起这一幕，想一次笑一次，我觉得自己是个傻帽"，直接从当年的故事跳回叙述者的现在。

## 2. 叙事节奏

- **单元剧式结构**：全书由一个又一个"故事单元"组成，每个单元是一次下墓/一次冒险/一段奇遇，每个单元有自己的起承转合
- 每个单元内部节奏：前1-2章铺垫（接活、准备、进山/到地方）→ 中间5-10章下墓冒险（遇到机关、诡异事件、团队冲突）→ 最后1-2章收尾（出货、分钱、各奔东西）
- **爽点密度**：平均每2-3章一个小爽点（找到好东西、识破骗局、化险为夷），每10章左右一个大爽点（找到大墓、发大财、打败对手）
- **章末钩子**：几乎每章末尾都有钩子，不是新事件发生就是新发现出现，让读者想继续看下一章
- 整体节奏偏快，几乎没有日常水章，每章都有新信息或新事件推进
- 但每个单元之间会有短暂的"过渡章"，交代时间流逝、人物状态变化，节奏稍缓

原文证据：第2章末"就这时，背后有人拍了我一下"（钩子，引出王把头），第6章末"这西周墓被人摸过了！"（钩子，引出后续剧情）。

## 3. 叙事距离

- **极近距离**：因为是第一人称回忆，叙述者几乎贴着读者的耳朵说话，像私下聊天一样
- "我"的心理活动非常多且毫无保留——害怕就说害怕、贪财就说贪财、后悔就说后悔，不装、不端着
- 读者和"我"的信息完全同步，"我"不知道的读者也不知道，"我"猜错的读者也跟着猜错
- 但回忆视角又让读者比当年的"我"多知道一层——"我后来才知道""结果证明我错了"，这种信息差制造了回望感
- 对其他人物，读者通过"我"的眼睛看，距离稍远，但"我"观察很细、感受很真实，所以其他人物也很立体

原文证据：第2章被光头摊主骗了之后，"我眼睛一红，急眼了，当时抓着他胳膊不松手，嚷嚷着要他把钱还我"，情绪和动作都直接甩出来，没有任何距离感。

## 4. 时间处理

- **基本线性时间**，按时间顺序推进，从16岁离家写到中年出狱
- 但因为是回忆式叙述，经常有"插叙"和"补叙"——讲到一个人或一件事，突然跳出来补充"后来这个人怎么样了""我后来才知道当时的真相"
- 时间跨度大（十几年），但每个故事单元内部是连续时间，节奏紧凑
- 时间过渡非常直白："两年后""过了半个月""第二天""当晚"，没有模糊的时间处理
- 没有倒叙、没有闪回（人物不会在行动中突然回忆），所有"回忆"都是叙述者站在"现在"回望"过去"，是框架层面的回忆

原文证据：第2章钱被偷后，"时至今日，我对这种火车站附近的小旅馆都没有好感"，就是站在现在回望过去的评论。

## 5. 信息控制

- **读者和主角信息基本同步**（除了回忆视角的补充信息），主角不知道的读者也不知道
- 悬念主要靠"未知"制造——墓里有什么、前面有什么危险、这个人是好人坏人，读者和主角一起探索
- **知识科普型信息释放**：作者特别喜欢在剧情推进中穿插"知识点"——盗墓行规、古董鉴定、历史知识、风水口诀，这些信息既是科普也是伏笔
- 伏笔手法：把重要线索混在"知识点科普"里，读者以为只是作者在讲知识，其实是伏笔
- 每个故事单元的关键信息（墓的位置、对手的身份、危险的来源）都是逐步释放的，不会一开始就全说
- 单元之间会留下长线伏笔（比如"长春会""姚师爷"），隔了很久才回收

原文证据：第4章大段讲北派南派、讲团伙分工，看起来只是科普行内知识，但这些信息后面都会用到——散土的工作方式、眼把头的重要性，都是后续剧情的基础。
